Selettore CSS per Tabelle

⏱ 20 minuti · Selettori di tipo · color · table · td

Descrizione

In questo esercizio imparerai a utilizzare i selettori di tipo per stilizzare gli elementi di una tabella HTML. Cambierai il colore del testo di tutte le celle della tabella in grigio utilizzando il selettore table td.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una tabella:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 4</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <table>
                <tr>
                  <td>Riga 1, Colonna 1</td>
                  <td>Riga 1, Colonna 2</td>
                </tr>
                <tr>
                  <td>Riga 2, Colonna 1</td>
                  <td>Riga 2, Colonna 2</td>
                </tr>
              </table>
            </body>
          </html>

Struttura della tabella:

  • <table> — Contenitore principale della tabella
  • <tr> — Table Row (riga della tabella)
  • <td> — Table Data (cella di dati)

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare stili alle celle della tabella

All'interno del file style.css, scrivi una regola CSS che selezioni tutte le celle (td) all'interno di una tabella e imposti il loro colore a grigio:

style.css
          table td {
            color: grey;
          }

Spiegazione:

  • table td è un selettore discendente che seleziona tutti gli elementi td che si trovano all'interno di un elemento table
  • Questo garantisce che solo le celle dentro una tabella vengano stilizzate
  • color: grey; imposta il colore del testo a grigio

Passo 4 — Migliorare l'aspetto della tabella (opzionale)

Per rendere la tabella più leggibile, puoi aggiungere bordi e spaziatura:

style.css — Con stili aggiuntivi
          table {
            border-collapse: collapse;
          }

          table td {
            color: grey;
            border: 1px solid #ccc;
            padding: 10px;
          }

Nuove proprietà aggiunte:

  • border-collapse: collapse; — Unisce i bordi delle celle adiacenti
  • border: 1px solid #ccc; — Aggiunge un bordo grigio chiaro
  • padding: 10px; — Aggiunge spazio interno alle celle

Risultato atteso

Aprendo il file HTML nel browser, dovresti vedere:

  • Una tabella con 2 righe e 2 colonne
  • Tutto il testo nelle celle di colore grigio
  • Con gli stili opzionali: bordi attorno alle celle e spaziatura interna

Approfondimenti

Selettori discendenti:

Un selettore discendente (come table td) seleziona tutti gli elementi che si trovano all'interno di un altro elemento, indipendentemente da quanto sono annidati. Nel nostro caso, table td seleziona tutti i td all'interno di un table, anche se ci sono altri elementi in mezzo (come tr).

Altri elementi delle tabelle:

  • <th> — Table Header (intestazione di colonna, di solito in grassetto)
  • <thead> — Raggruppa le righe di intestazione
  • <tbody> — Raggruppa le righe del corpo della tabella
  • <tfoot> — Raggruppa le righe di piè di pagina

Selettori alternativi:

  • td — Seleziona tutti i td nella pagina (non solo nelle tabelle)
  • table > tr > td — Selettore figlio diretto (più specifico)
  • table th — Seleziona le celle di intestazione
