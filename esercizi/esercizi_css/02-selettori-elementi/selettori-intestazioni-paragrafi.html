Selettori CSS per Intestazioni e Paragrafi

⏱ 20 minuti · Selettori di tipo · color · h1, h2, h3 · p

Descrizione

In questo esercizio imparerai a utilizzare i selettori di tipo (o selettori di elementi) per applicare stili CSS a tutti gli elementi di un certo tipo nella pagina. Cambierai il colore del testo di tutte le intestazioni (h1, h2, h3) in blu e il colore di tutti i paragrafi in verde.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con diverse intestazioni e paragrafi:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 1</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <h1>Titolo livello 1</h1>
              <h2>Titolo livello 2</h2>
              <h3>Titolo livello 3</h3>
              <p>Questo è un paragrafo.</p>
              <p>E questo è un altro paragrafo.</p>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare stili alle intestazioni

All'interno del file style.css, scrivi una regola CSS che selezioni tutti gli elementi h1, h2, e h3 e imposti il loro colore a blu:

style.css
          h1,
          h2,
          h3 {
            color: blue;
          }

Spiegazione:

  • I selettori separati da virgola (h1, h2, h3) permettono di applicare le stesse regole a più elementi
  • color: blue; imposta il colore del testo a blu

Passo 4 — Applicare stili ai paragrafi

Aggiungi al file style.css una regola CSS per i paragrafi:

style.css — Completo
          h1,
          h2,
          h3 {
            color: blue;
          }

          p {
            color: green;
          }

Risultato atteso

Aprendo il file HTML nel browser, dovresti vedere:

  • Tutte le intestazioni (h1, h2, h3) con testo di colore blu
  • Tutti i paragrafi con testo di colore verde

Approfondimenti

Cos'è un selettore di tipo?

Un selettore di tipo (o selettore di elemento) seleziona tutti gli elementi HTML di un determinato tipo. Ad esempio, p seleziona tutti i paragrafi, div seleziona tutti i div, ecc.

Raggruppamento di selettori:

Quando vuoi applicare le stesse regole CSS a più tipi di elementi, puoi raggrupparli separandoli con virgole. Questo rende il codice più compatto e manutenibile.

Altri selettori di tipo comuni:

  • div — Seleziona tutti i div
  • a — Seleziona tutti i link
  • ul — Seleziona tutte le liste non ordinate
  • table — Seleziona tutte le tabelle
