Base Flexbox #1

Flexbox: elementi in riga

⏱ 15 minuti · display:flex · flex-container · flex-item

Descrizione

In questo esercizio creerai il tuo primo layout con Flexbox. Flexbox è un sistema di layout CSS che permette di distribuire e allineare elementi in modo semplice e flessibile. L'obiettivo è disporre tre <div> in riga orizzontale usando la proprietà display: flex sul loro contenitore.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html. Aggiungi un <div> contenitore con tre <div> figli all'interno. Ricorda di collegare il file CSS esterno con il tag <link>:

index.html
          <!DOCTYPE html>
          <html lang="it">
            <head>
              <title>Flexbox Riga</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="flex-container">
                <div class="flex-item">Elemento 1</div>
                <div class="flex-item">Elemento 2</div>
                <div class="flex-item">Elemento 3</div>
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella di index.html. Applica display: flex al contenitore e aggiungi un bordo e un padding agli elementi figli:

style.css
          .flex-container {
            display: flex;
          }

          .flex-item {
            padding: 10px;
            border: 1px solid black;
          }

Passo 3 — Come funziona display: flex

Quando applichi display: flex a un elemento, quel elemento diventa il flex container e i suoi figli diretti diventano i flex item. Per impostazione predefinita, i flex item si dispongono in riga (flex-direction: row).

Termine Significato
Flex container L'elemento padre su cui si applica display: flex
Flex item Ogni figlio diretto del flex container
Asse principale La direzione in cui si dispongono gli item (per default: orizzontale)
Asse trasversale La direzione perpendicolare all'asse principale

Risultato atteso

I tre div si disporranno fianco a fianco in orizzontale, ciascuno con un bordo visibile e un po' di padding interno.

Approfondimenti

Perché i div normalmente si impilano in verticale?

Il <div> è un elemento block-level: per impostazione predefinita occupa tutta la larghezza disponibile e si dispone sotto il precedente. Con display: flex, il comportamento dei figli cambia: si dispongono lungo l'asse principale del container, che di default è orizzontale.
