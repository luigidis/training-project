Flexbox: riga centrata

⏱ 15 minuti · display:flex · justify-content · center

Descrizione

In questo esercizio userai la proprietà justify-content di Flexbox per centrare orizzontalmente cinque elementi <div> all'interno del loro contenitore. justify-content controlla la distribuzione degli item lungo l'asse principale del flex container.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html con cinque elementi .flex-item dentro un .flex-container. Collega il file CSS esterno tramite il tag <link>:

index.html
          <!DOCTYPE html>
          <html lang="it">
            <head>
              <title>Flexbox Riga Centrata</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="flex-container">
                <div class="flex-item">Elemento 1</div>
                <div class="flex-item">Elemento 2</div>
                <div class="flex-item">Elemento 3</div>
                <div class="flex-item">Elemento 4</div>
                <div class="flex-item">Elemento 5</div>
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS con justify-content

Crea un nuovo file chiamato style.css nella stessa cartella di index.html. Usa justify-content: center per centrare gli elementi lungo l'asse orizzontale:

style.css
          .flex-container {
            display: flex;
            justify-content: center;
          }

          .flex-item {
            padding: 10px;
            border: 1px solid black;
          }

Passo 3 — I valori di justify-content

justify-content controlla come vengono distribuiti gli elementi lungo l'asse principale. Ecco i valori più utilizzati:

Valore Effetto
flex-start Tutti gli item raggruppati all'inizio (sinistra per righe)
flex-end Tutti gli item raggruppati alla fine (destra per righe)
center Tutti gli item centrati
space-between Spazio uguale tra gli item, niente spazio ai bordi
space-around Spazio uguale intorno a ogni item
space-evenly Spazio identico tra tutti gli item e i bordi

Passo 4 — Prova gli altri valori (opzionale)

Sostituisci center con gli altri valori della tabella per osservare la differenza nel browser. Prova anche ad aggiungere un colore di sfondo al container per rendere visibile lo spazio disponibile:

style.css — Variante con sfondo
          .flex-container {
            display: flex;
            justify-content: space-between;
            background-color: #f0f0f0;
            padding: 10px;
          }

          .flex-item {
            padding: 10px;
            border: 1px solid black;
            background-color: white;
          }

Risultato atteso

I cinque elementi si disporranno in riga orizzontale e saranno raggruppati al centro della pagina, con spazio libero ai lati.

Approfondimenti

Differenza tra justify-content e align-items:

justify-content agisce sull'asse principale (orizzontale di default), mentre align-items agisce sull'asse trasversale (verticale di default). Per centrare gli elementi sia in orizzontale che in verticale si usano entrambe le proprietà insieme: justify-content: center; align-items: center;.
