Base Flexbox #3

Flexbox: colonna allineata a destra

⏱ 15 minuti · flex-direction · column · align-items · flex-end

Descrizione

In questo esercizio userai flex-direction: column per disporre quattro elementi in verticale, e align-items: flex-end per allinearli al lato destro del contenitore. Imparerai la differenza tra asse principale e asse trasversale quando la direzione del flex cambia.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html con quattro elementi .flex-item dentro un .flex-container. Collega il file CSS esterno tramite il tag <link>:

index.html
          <!DOCTYPE html>
          <html lang="it">
            <head>
              <title>Flexbox Colonna Destra</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="flex-container">
                <div class="flex-item">Elemento 1</div>
                <div class="flex-item">Elemento 2</div>
                <div class="flex-item">Elemento 3</div>
                <div class="flex-item">Elemento 4</div>
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella di index.html. Usa flex-direction: column per disporre gli elementi in verticale e align-items: flex-end per spostarli a destra:

style.css
          .flex-container {
            display: flex;
            flex-direction: column;
            align-items: flex-end;
          }

          .flex-item {
            padding: 10px;
            border: 1px solid black;
          }

Passo 3 — Asse principale e asse trasversale con column

Quando cambi flex-direction, cambiano anche gli assi. Questo è fondamentale per capire perché align-items e non justify-content agisce sull'allineamento orizzontale in modalità colonna:

Proprietà Con flex-direction: row Con flex-direction: column
justify-content Allinea in orizzontale Allinea in verticale
align-items Allinea in verticale Allinea in orizzontale

Passo 4 — Valori di align-items

Prova a sostituire flex-end con gli altri valori disponibili per osservare il comportamento degli elementi:

Valore Effetto
flex-start Allinea gli item all'inizio dell'asse trasversale (sinistra in modalità colonna)
flex-end Allinea gli item alla fine dell'asse trasversale (destra in modalità colonna)
center Centra gli item sull'asse trasversale
stretch Estende gli item per occupare tutta la larghezza disponibile (valore di default)

Risultato atteso

I quattro elementi si disporranno uno sotto l'altro in verticale, tutti allineati al lato destro del contenitore.

Approfondimenti

Perché il container deve avere una larghezza esplicita?

Per vedere l'effetto di align-items: flex-end, il container deve essere più largo degli item. Se tutti gli item hanno la stessa larghezza del container, non ci sarà differenza visiva. Prova ad aggiungere width: 400px; al .flex-container per osservare meglio il risultato.
