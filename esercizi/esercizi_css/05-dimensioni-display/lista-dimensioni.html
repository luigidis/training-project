Lista con Dimensioni Personalizzate

⏱ 25 minuti · ul · li · Dimensioni elementi · list-style-type · margin

Descrizione

In questo esercizio imparerai a stilizzare gli elementi di una lista non ordinata (<ul>) applicando dimensioni personalizzate, vincoli di min/max, e altre proprietà CSS per creare una lista visivamente più accattivante.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una lista non ordinata contenente tre elementi:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 8</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <ul>
                <li>Elemento 1</li>
                <li>Elemento 2</li>
                <li>Elemento 3</li>
              </ul>
            </body>
          </html>

Passo 2 — Creare il file CSS e stilizzare gli elementi della lista

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. All'interno del file CSS, definisci le regole CSS per gli elementi <li>:

style.css
          li {
            width: 180px;
            height: 40px;
            min-height: 30px;
            max-width: 200px;
            background-color: lightpink;
            margin: 5px;
            list-style-type: none;
          }

Passo 3 — Comprendere le proprietà applicate

Proprietà Valore Significato
width 180px Ogni elemento della lista è largo 180 pixel
height 40px Ogni elemento della lista è alto 40 pixel
min-height 30px L'altezza minima garantita è 30px
max-width 200px La larghezza massima consentita è 200px
background-color lightpink Sfondo rosa chiaro per evidenziare gli elementi
margin 5px Spazio esterno di 5px attorno a ogni elemento
list-style-type none Rimuove i pallini/marker della lista

Passo 4 — Testare i vincoli

Prova a modificare i valori per vedere come si comportano i vincoli:

  1. Imposta width: 250px; — l'elemento resterà 200px (max-width)
  2. Imposta height: 20px; — l'elemento resterà 30px (min-height)
  3. Imposta width: 150px; — l'elemento sarà 150px (valore valido)

Passo 5 — Personalizzazione avanzata (opzionale)

Puoi aggiungere altre proprietà al file style.css per migliorare l'aspetto:

style.css — Stilizzazione avanzata
          li {
            width: 180px;
            height: 40px;
            min-height: 30px;
            max-width: 200px;
            background-color: lightpink;
            margin: 5px;
            list-style-type: none;
            padding: 10px;
            border-radius: 5px;
            box-shadow: 2px 2px 5px rgba(0,0,0,0.1);
          }

Nuove proprietà aggiunte:

  • padding: 10px; — Spazio interno tra il bordo e il contenuto
  • border-radius: 5px; — Angoli arrotondati
  • box-shadow: — Ombra leggera per dare profondità

Risultato atteso

Gli elementi della lista avranno:

  • Larghezza di 180px, con massimo di 200px
  • Altezza di 40px, con minimo di 30px
  • Sfondo rosa chiaro
  • Spaziatura tra gli elementi (5px)
  • Nessun marker/pallino (list-style-type: none)

Approfondimenti

Altre proprietà utili per le liste:

  • list-style-type: disc; — Pallino pieno (default)
  • list-style-type: circle; — Pallino vuoto
  • list-style-type: square; — Quadrato
  • list-style-position: inside; — Marker all'interno dell'elemento
  • list-style-image: url('icon.png'); — Icona personalizzata come marker

Indice dei passi

  1. Struttura HTML
  2. Stilizzare gli elementi
  3. Comprendere le proprietà
  4. Testare i vincoli
  5. Personalizzazione avanzata

Proprietà CSS

  • min/max
  • list-style-type
  • margin
