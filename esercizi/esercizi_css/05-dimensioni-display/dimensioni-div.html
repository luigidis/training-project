Base Esercizio CSS #2

Dimensioni di un Div con min/max

⏱ 20 minuti · width · height · min-height · max-width

Descrizione

In questo esercizio imparerai a controllare le dimensioni di un elemento <div> utilizzando le proprietà CSS width, height, min-height e max-width. Queste proprietà sono fondamentali per creare layout responsive e controllati.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un div contenente del testo:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 7</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div>
                Questo div ha una larghezza di 800px e un'altezza di 200px,
                ma non scende mai sotto i 150px in altezza e non supera
                mai i 900px in larghezza.
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. All'interno del file CSS, definisci le dimensioni del div:

style.css
          div {
            width: 800px;
            height: 200px;
            background-color: lightgreen;
          }

Risultato parziale: Il div avrà una larghezza di 800px e un'altezza di 200px con sfondo verde chiaro.

Passo 3 — Aggiungere i vincoli min/max

Ora modifica il file style.css aggiungendo le proprietà min-height e max-width per creare dei limiti che il div non può superare:

style.css — Con vincoli
          div {
            width: 800px;
            height: 200px;
            min-height: 150px;
            max-width: 900px;
            background-color: lightgreen;
          }

Passo 4 — Comprendere i vincoli

Cosa significa ogni proprietà:

Proprietà Valore Significato
width 800px Il div è largo 800 pixel
height 200px Il div è alto 200 pixel
min-height 150px L'altezza minima garantita è 150px (non può essere più basso)
max-width 900px La larghezza massima consentita è 900px (non può essere più largo)

Passo 5 — Testare i vincoli

Per verificare che i vincoli funzionino correttamente, prova a:

  1. Cambiare width: 1000px; — il div resterà comunque 900px perché è il massimo consentito
  2. Cambiare height: 100px; — il div resterà comunque 150px perché è il minimo consentito
  3. Cambiare width: 700px; — il div sarà 700px (valore valido, sotto il massimo)

Risultato atteso

Il div avrà una larghezza di 800px e un'altezza di 200px con sfondo verde chiaro. Se provi a ridimensionarlo con altri valori, rispetterà sempre i vincoli:

  • Non scenderà mai sotto i 150px di altezza
  • Non supererà mai i 900px di larghezza

Approfondimenti

Quando usare min/max?

  • min-height: Utile quando il contenuto potrebbe variare, ma vuoi garantire un'altezza minima
  • max-width: Fondamentale per layout responsive, impedisce che gli elementi diventino troppo larghi su schermi grandi
  • min-width: Garantisce che un elemento non diventi troppo stretto
  • max-height: Limita l'altezza massima di un elemento
