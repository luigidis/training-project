Grid: spaziatura tra celle

⏱ 15 minuti · display:grid · gap · column-gap · row-gap

Descrizione

In questo esercizio creerai una griglia CSS di 4 colonne e imposterai una spaziatura di 20 pixel tra tutte le celle usando la proprietà gap. Imparerai la differenza tra gap, column-gap e row-gap, e come la spaziatura si comporta con il layout a griglia.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html con otto elementi .grid-item dentro un .grid-container (due righe da quattro colonne). Collega il file CSS esterno tramite il tag <link>:

index.html
          <!DOCTYPE html>
          <html lang="it">
            <head>
              <title>Grid Gap</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="grid-container">
                <div class="grid-item">1</div>
                <div class="grid-item">2</div>
                <div class="grid-item">3</div>
                <div class="grid-item">4</div>
                <div class="grid-item">5</div>
                <div class="grid-item">6</div>
                <div class="grid-item">7</div>
                <div class="grid-item">8</div>
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS con gap

Crea un nuovo file chiamato style.css nella stessa cartella di index.html. Usa gap: 20px per impostare la stessa spaziatura sia tra le colonne che tra le righe:

style.css
          .grid-container {
            display: grid;
            grid-template-columns: repeat(4, 1fr);
            gap: 20px;
          }

          .grid-item {
            padding: 10px;
            border: 1px solid black;
          }

Passo 3 — gap, column-gap e row-gap

La proprietà gap è una scorciatoia che imposta sia lo spazio tra le righe (row-gap) che tra le colonne (column-gap):

Proprietà Effetto
gap: 20px 20px tra righe e 20px tra colonne
gap: 10px 20px 10px tra righe, 20px tra colonne
row-gap: 10px Solo 10px tra le righe
column-gap: 20px Solo 20px tra le colonne

Passo 4 — Prova spaziature diverse (opzionale)

Sostituisci gap: 20px con gap: 10px 40px per avere una spaziatura verticale diversa da quella orizzontale, e osserva il risultato nel browser:

style.css — Spaziatura asimmetrica
          .grid-container {
            display: grid;
            grid-template-columns: repeat(4, 1fr);
            gap: 10px 40px; /* riga colonna */
          }

Risultato atteso

Una griglia di 4 colonne × 2 righe in cui ogni cella è separata dalle adiacenti da uno spazio uniforme di 20 pixel, sia orizzontalmente che verticalmente.

Approfondimenti

gap non aggiunge spazio ai bordi esterni:

A differenza del margin, la proprietà gap inserisce spazio solo tra gli elementi, mai tra un elemento e il bordo del container. Per aggiungere spazio esterno usa padding sul container.
