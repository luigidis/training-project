Base Grid #4

Grid: prima riga a altezza fissa

⏱ 20 minuti · grid-template-rows · fr · px · layout header

Descrizione

In questo esercizio creerai una griglia CSS di 3 colonne e 3 righe in cui la prima riga è alta esattamente 100 pixel mentre le altre due si dividono equamente lo spazio rimanente. Questo pattern è tipico dei layout con header fisso: la prima riga funge da intestazione e il resto dalla zona di contenuto.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html con nove elementi .grid-item dentro un .grid-container (3 colonne × 3 righe = 9 celle). Collega il file CSS esterno tramite il tag <link>:

index.html
          <!DOCTYPE html>
          <html lang="it">
            <head>
              <title>Grid Riga Fissa</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="grid-container">
                <div class="grid-item">Header 1</div>
                <div class="grid-item">Header 2</div>
                <div class="grid-item">Header 3</div>
                <div class="grid-item">Riga 2 - 1</div>
                <div class="grid-item">Riga 2 - 2</div>
                <div class="grid-item">Riga 2 - 3</div>
                <div class="grid-item">Riga 3 - 1</div>
                <div class="grid-item">Riga 3 - 2</div>
                <div class="grid-item">Riga 3 - 3</div>
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella di index.html. Il container deve avere un'altezza esplicita (ad es. 300px) per rendere visibile la distribuzione delle righe con fr:

style.css
          .grid-container {
            display: grid;
            grid-template-columns: repeat(3, 1fr);
            grid-template-rows: 100px 1fr 1fr;
            gap: 10px;
            height: 300px;
          }

          .grid-item {
            padding: 10px;
            border: 1px solid black;
            box-sizing: border-box;
          }

Passo 3 — Come si legge grid-template-rows: 100px 1fr 1fr

Ogni valore separato da uno spazio corrisponde a una riga, nell'ordine dall'alto verso il basso:

Valore Riga Comportamento
100px Riga 1 (header) Altezza fissa, non cambia mai
1fr Riga 2 Occupa metà dello spazio rimanente
1fr Riga 3 Occupa l'altra metà dello spazio rimanente

Passo 4 — Variante con auto per le righe di contenuto (opzionale)

Invece di 1fr puoi usare auto per far crescere le righe in base al loro contenuto. Prova a confrontare il comportamento aggiungendo testo lungo in una delle celle:

style.css — Variante con auto
          .grid-container {
            display: grid;
            grid-template-columns: repeat(3, 1fr);
            grid-template-rows: 100px auto auto;
            gap: 10px;
          }

Risultato atteso

La prima riga occuperà esattamente 100 pixel di altezza. Le righe 2 e 3 si divideranno equamente lo spazio rimanente all'interno del container.

Approfondimenti

Questo pattern in un layout reale:

Il pattern grid-template-rows: 60px 1fr (o simili) è molto usato per costruire layout a pagina intera con header fisso e contenuto scorrevole. Combinato con height: 100vh sul container, permette di creare applicazioni web in cui la barra di navigazione rimane visibile mentre il contenuto occupa il resto dello schermo.
