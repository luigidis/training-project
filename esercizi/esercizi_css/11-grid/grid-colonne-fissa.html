Grid: colonna a larghezza fissa

⏱ 20 minuti · display:grid · grid-template-columns · fr · px

Descrizione

In questo esercizio creerai una griglia CSS di 5 colonne in cui la quarta colonna ha una larghezza fissa di 150 pixel, mentre le altre quattro si adattano proporzionalmente allo spazio rimanente. Imparerai a usare display: grid e la funzione repeat() insieme all'unità frazionale fr.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html con cinque elementi .grid-item dentro un .grid-container. Collega il file CSS esterno tramite il tag <link>:

index.html
          <!DOCTYPE html>
          <html lang="it">
            <head>
              <title>Grid Colonna Fissa</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="grid-container">
                <div class="grid-item">Colonna 1</div>
                <div class="grid-item">Colonna 2</div>
                <div class="grid-item">Colonna 3</div>
                <div class="grid-item">Colonna 4</div>
                <div class="grid-item">Colonna 5</div>
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella di index.html. In grid-template-columns definisci ogni colonna separata da uno spazio: le prime tre e l'ultima usano 1fr, la quarta usa 150px:

style.css
          .grid-container {
            display: grid;
            grid-template-columns: 1fr 1fr 1fr 150px 1fr;
            gap: 10px;
          }

          .grid-item {
            padding: 10px;
            border: 1px solid black;
          }

Passo 3 — Cos'è l'unità fr?

L'unità fr (fraction) rappresenta una frazione dello spazio disponibile nel grid container. Dopo aver sottratto le colonne a dimensione fissa (come 150px), lo spazio rimanente viene diviso in frazioni uguali tra le colonne che usano fr:

Definizione colonne Risultato
1fr 1fr 1fr Tre colonne di uguale larghezza
2fr 1fr Prima colonna larga il doppio della seconda
1fr 150px 1fr Colonna centrale fissa, le altre si dividono lo spazio restante

Passo 4 — Usare repeat() (opzionale)

La funzione repeat() permette di abbreviare la definizione quando più colonne hanno lo stesso valore. Puoi riscrivere l'esercizio usando repeat() per le colonne 1fr:

style.css — Variante con repeat()
          .grid-container {
            display: grid;
            /* Equivalente a: 1fr 1fr 1fr 150px 1fr */
            grid-template-columns: repeat(3, 1fr) 150px 1fr;
            gap: 10px;
          }

Risultato atteso

Cinque celle in riga: le prime tre e l'ultima si dividono equamente lo spazio disponibile, mentre la quarta rimane fissa a 150 pixel indipendentemente dalla larghezza della finestra.

Approfondimenti

Differenza tra fr e %:

Con % la larghezza è calcolata rispetto al container totale, incluso il gap. Con fr lo spazio viene distribuito dopo aver tolto il gap e le colonne fisse, evitando il problema del overflow quando si sommano percentuali e gap.
