Grid: dimensioni fisse per righe e colonne

⏱ 20 minuti · grid-template-columns · grid-template-rows · px

Descrizione

In questo esercizio creerai una griglia CSS di 5 colonne e 2 righe con dimensioni completamente fisse: ogni colonna sarà larga 100 pixel e ogni riga sarà alta 50 pixel. Userai sia grid-template-columns che grid-template-rows insieme.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html con dieci elementi .grid-item dentro un .grid-container (5 colonne × 2 righe = 10 celle). Collega il file CSS esterno tramite il tag <link>:

index.html
          <!DOCTYPE html>
          <html lang="it">
            <head>
              <title>Grid Dimensioni Fisse</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="grid-container">
                <div class="grid-item">1</div>
                <div class="grid-item">2</div>
                <div class="grid-item">3</div>
                <div class="grid-item">4</div>
                <div class="grid-item">5</div>
                <div class="grid-item">6</div>
                <div class="grid-item">7</div>
                <div class="grid-item">8</div>
                <div class="grid-item">9</div>
                <div class="grid-item">10</div>
              </div>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella di index.html. Usa repeat() per definire sia le colonne che le righe con dimensioni fisse:

style.css
          .grid-container {
            display: grid;
            grid-template-columns: repeat(5, 100px);
            grid-template-rows: repeat(2, 50px);
            gap: 10px;
          }

          .grid-item {
            padding: 10px;
            border: 1px solid black;
          }

Passo 3 — grid-template-rows

Così come grid-template-columns controlla la larghezza delle colonne, grid-template-rows controlla l'altezza delle righe. Il suo funzionamento è identico: si elencano i valori separati da uno spazio o si usa repeat():

Definizione Risultato
grid-template-rows: 50px 50px Due righe alte 50px ciascuna
grid-template-rows: repeat(2, 50px) Identico alla riga sopra, scritto in modo più compatto
grid-template-rows: 100px 1fr Prima riga fissa a 100px, seconda che occupa lo spazio rimanente

Passo 4 — Osserva l'overflow (opzionale)

Il padding: 10px che hai messo sugli item potrebbe far traboccare il contenuto dalle celle di 50px. Questo dipende dal box-sizing. Prova ad aggiungere box-sizing: border-box al .grid-item per includere il padding nelle dimensioni della cella:

style.css — Con box-sizing
          .grid-item {
            padding: 10px;
            border: 1px solid black;
            box-sizing: border-box;
          }

Risultato atteso

Una griglia di 5 colonne × 2 righe in cui ogni cella ha esattamente 100px di larghezza e 50px di altezza, indipendentemente dal contenuto o dalla finestra del browser.

Approfondimenti

Griglia rigida vs. griglia flessibile:

Una griglia con dimensioni fisse in pixel non si adatta alle diverse dimensioni dello schermo. Nelle applicazioni reali si preferisce usare fr, minmax() o auto per creare griglie responsive. Le dimensioni fisse sono utili invece per componenti UI precisi come icone, celle di tabella o pixel art.
