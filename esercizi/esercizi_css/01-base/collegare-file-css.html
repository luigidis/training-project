Collegare un File CSS Esterno

⏱ 15 minuti · Tag link · Selettori CSS · Proprietà color

Descrizione

In questo esercizio imparerai a collegare un file CSS esterno al tuo documento HTML e a utilizzare i selettori CSS per applicare stili agli elementi della pagina. Questo è il primo passo fondamentale per separare la struttura (HTML) dalla presentazione (CSS).

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con la seguente struttura base:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 2</title>
            </head>
            <body>
              <p>Questo testo sarà blu.</p>
            </body>
          </html>

Passo 2 — Collegare il file CSS esterno

All'interno del tag <head>, aggiungi il tag <link> per collegare il file CSS esterno chiamato style.css:

Aggiungere nel <head>
          <link rel="stylesheet" href="style.css" />

Spiegazione degli attributi:

  • rel="stylesheet" — indica che il file collegato è un foglio di stile
  • href="style.css" — specifica il percorso del file CSS

Passo 3 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. All'interno del file CSS, scrivi la seguente regola per rendere il testo dei paragrafi di colore blu:

style.css
          p {
            color: blue;
          }

Spiegazione della regola CSS:

  • p — selettore che punta a tutti gli elementi <p> (paragrafi)
  • color: blue; — proprietà che imposta il colore del testo a blu

Passo 4 — Verificare il risultato

Apri il file index.html nel tuo browser. Dovresti vedere il testo del paragrafo visualizzato in colore blu. Se il testo è ancora nero, verifica che:

  1. Il file CSS si chiami esattamente style.css
  2. Il file CSS sia nella stessa cartella del file HTML
  3. Il tag <link> sia scritto correttamente nel <head>

Risultato atteso

Il browser mostrerà il testo "Questo testo sarà blu." in colore blu.

Approfondimenti

Perché usare un file CSS esterno?

  • Separazione tra struttura e presentazione
  • Riutilizzo degli stili su più pagine
  • Manutenzione più semplice del codice
  • Prestazioni migliori (il browser può memorizzare in cache il file CSS)

Indice dei passi

  1. Struttura HTML
  2. Collegare il CSS
  3. Creare il file CSS
  4. Verificare il risultato
