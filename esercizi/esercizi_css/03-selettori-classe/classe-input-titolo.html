Selettori di Classe per Input e Titolo

⏱ 20 minuti · Selettori di classe · color · input · h2

Descrizione

In questo esercizio continuerai a praticare con i selettori di classe applicandoli a diversi tipi di elementi HTML. Assegnerai la classe "campo-input" a un campo di input e la classe "titolo" a un'intestazione, quindi userai i selettori CSS per cambiare il colore del testo.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un input e un'intestazione:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 3</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <input
                type="text"
                class="campo-input"
                placeholder="Inserisci il testo qui" />
              <h2 class="titolo">Titolo dell'intestazione</h2>
            </body>
          </html>

Elementi HTML utilizzati:

  • <input type="text"> — Campo di testo dove l'utente può inserire dati
  • placeholder — Testo di esempio che appare nel campo vuoto
  • class="campo-input" — Classe assegnata al campo di input
  • class="titolo" — Classe assegnata all'intestazione

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare stili con selettori di classe

All'interno del file style.css, scrivi le regole CSS per stilizzare gli elementi usando i selettori di classe:

style.css
          .campo-input {
            color: blue;
          }

          .titolo {
            color: green;
          }

Spiegazione:

  • .campo-input — Seleziona l'elemento con class="campo-input" (il campo di input)
  • .titolo — Seleziona l'elemento con class="titolo" (l'intestazione h2)
  • Il colore applicato agli input influenza il testo che l'utente digita

Passo 4 — Migliorare lo stile del campo di input (opzionale)

Puoi aggiungere altre proprietà CSS per rendere il campo di input più accattivante:

style.css — Con stili aggiuntivi
          .campo-input {
            color: blue;
            font-size: 16px;
            padding: 10px;
            border: 2px solid blue;
            border-radius: 5px;
            width: 300px;
          }

          .titolo {
            color: green;
          }

Nuove proprietà aggiunte:

  • font-size: 16px; — Dimensione del carattere
  • padding: 10px; — Spazio interno nel campo
  • border: 2px solid blue; — Bordo blu di 2 pixel
  • border-radius: 5px; — Angoli arrotondati
  • width: 300px; — Larghezza del campo

Risultato atteso

Aprendo il file HTML nel browser, dovresti vedere:

  • Un campo di input con testo di colore blu (quando digiti)
  • Un'intestazione "Titolo dell'intestazione" con testo di colore verde
  • Con gli stili opzionali: un campo di input stilizzato con bordo blu e angoli arrotondati

Approfondimenti

Stilizzare campi di input:

I campi di input possono essere stilizzati con molte proprietà CSS per migliorare l'esperienza utente. È importante rendere i campi di input chiaramente visibili e facili da usare.

Nomi di classi significativi:

Nota come la classe campo-input usa un nome descrittivo che spiega cosa rappresenta l'elemento. Questa è una buona pratica che rende il codice più leggibile e manutenibile. Evita nomi generici come blu o elemento1.

Pseudo-classi per input:

  • input:focus — Stile quando l'input è selezionato
  • input:hover — Stile quando il mouse passa sopra
  • input:disabled — Stile quando l'input è disabilitato

Esempio con pseudo-classe focus:

CSS — Con effetto focus
          .campo-input:focus {
            outline: none;
            border-color: darkblue;
            box-shadow: 0 0 5px rgba(0, 0, 255, 0.5);
          }
