Selettore di Classe per Paragrafi

⏱ 15 minuti · Selettori di classe · color · riutilizzo classi

Descrizione

In questo esercizio imparerai un concetto fondamentale: la riutilizzabilità delle classi. Assegnerai la stessa classe "paragrafo" a tre diversi paragrafi, dimostrando come una singola regola CSS possa stilizzare più elementi contemporaneamente.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con tre paragrafi:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 5</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <p class="paragrafo">Questo è un paragrafo.</p>
              <p class="paragrafo">Questo è un altro paragrafo.</p>
              <p class="paragrafo">E ancora un altro paragrafo.</p>
            </body>
          </html>

Nota importante:

  • Tutti e tre i paragrafi hanno class="paragrafo"
  • La stessa classe può essere usata su più elementi
  • Una singola regola CSS si applicherà a tutti e tre i paragrafi

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare stili con il selettore di classe

All'interno del file style.css, scrivi una regola CSS per la classe "paragrafo":

style.css
          .paragrafo {
            color: blue;
          }

Cosa succede:

  • .paragrafo seleziona tutti gli elementi con class="paragrafo"
  • Questa singola regola CSS si applica ai tre paragrafi contemporaneamente
  • Modificando lo stile in un solo punto, cambiano tutti e tre i paragrafi

Passo 4 — Sperimentare con la riutilizzabilità

Per capire meglio il vantaggio delle classi, prova ad aggiungere altre proprietà:

style.css — Con più proprietà
          .paragrafo {
            color: blue;
            font-size: 18px;
            line-height: 1.6;
            margin-bottom: 15px;
          }

Risultato:

Tutte le proprietà vengono applicate ai tre paragrafi automaticamente. Questo dimostra l'efficienza delle classi: scrivi una volta, applica a molti elementi.

Risultato atteso

Aprendo il file HTML nel browser, dovresti vedere:

  • Tre paragrafi, tutti con testo di colore blu
  • Con gli stili opzionali: testo più grande, spaziatura tra le righe e margine sotto ogni paragrafo

Approfondimenti

Vantaggi della riutilizzabilità delle classi:

  • Manutenibilità: Modifichi lo stile in un solo punto invece che in tre
  • Coerenza: Garantisce che elementi simili abbiano lo stesso aspetto
  • Efficienza: Meno codice CSS da scrivere e mantenere
  • Scalabilità: Puoi aggiungere altri elementi con la stessa classe senza modificare il CSS

Confronto con selettori di tipo:

Approccio Codice CSS Effetto
Selettore di tipo p { color: blue; } Colora tutti i paragrafi della pagina in blu
Selettore di classe .paragrafo { color: blue; } Colora solo i paragrafi con class="paragrafo"

Quando usare classi vs selettori di tipo:

  • Usa selettori di tipo quando vuoi stilizzare tutti gli elementi di un tipo (es. tutti i link)
  • Usa selettori di classe quando vuoi stilizzare solo alcuni elementi specifici

Esempio pratico:

HTML — Paragrafi con e senza classe
          <p class="paragrafo">Questo sarà blu</p>
          <p>Questo avrà lo stile di default</p>
          <p class="paragrafo">Anche questo sarà blu</p>

Con .paragrafo { color: blue; }, solo il primo e terzo paragrafo saranno blu. Il secondo paragrafo, che non ha la classe, manterrà il colore predefinito.
