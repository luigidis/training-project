Selettori di Classe per Titolo e Testo

⏱ 20 minuti · Selettori di classe · color · class attribute

Descrizione

In questo esercizio imparerai a utilizzare i selettori di classe per applicare stili CSS a elementi specifici. Assegnerai la classe "titolo" a un'intestazione e la classe "testo" a un paragrafo, quindi userai i selettori CSS per cambiare il colore del titolo in blu e del testo in verde.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un'intestazione e un paragrafo:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 1</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <h1 class="titolo">Titolo dell'intestazione</h1>
              <p class="testo">Questo è un paragrafo.</p>
            </body>
          </html>

Nota importante:

  • L'attributo class="titolo" assegna la classe "titolo" all'intestazione
  • L'attributo class="testo" assegna la classe "testo" al paragrafo
  • Le classi permettono di identificare e stilizzare elementi specifici

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare stili con selettori di classe

All'interno del file style.css, scrivi le regole CSS usando i selettori di classe:

style.css
          .titolo {
            color: blue;
          }

          .testo {
            color: green;
          }

Spiegazione:

  • .titolo — Il punto (.) indica un selettore di classe che seleziona tutti gli elementi con class="titolo"
  • .testo — Seleziona tutti gli elementi con class="testo"
  • Il punto è fondamentale: senza di esso, CSS cercherebbe un elemento HTML chiamato "titolo" o "testo"

Risultato atteso

Aprendo il file HTML nel browser, dovresti vedere:

  • L'intestazione "Titolo dell'intestazione" con testo di colore blu
  • Il paragrafo "Questo è un paragrafo." con testo di colore verde

Approfondimenti

Differenza tra selettori di tipo e selettori di classe:

Tipo di selettore Sintassi Cosa seleziona Esempio
Selettore di tipo elemento Tutti gli elementi di quel tipo p { ... } seleziona tutti i paragrafi
Selettore di classe .classe Tutti gli elementi con quella classe .testo { ... } seleziona elementi con class="testo"

Vantaggi dei selettori di classe:

  • Riutilizzabilità: La stessa classe può essere applicata a più elementi diversi
  • Specificità: Puoi stilizzare solo alcuni elementi di un tipo, non tutti
  • Flessibilità: Un elemento può avere più classi separate da spazi: class="titolo importante"

Esempi di utilizzo:

HTML — Elementi con classi
          <p class="evidenziato">Testo evidenziato</p>
          <div class="evidenziato">Anche questo è evidenziato</div>
          <span class="evidenziato rosso">Con più classi</span>
CSS — Stili per le classi
          .evidenziato {
            background-color: yellow;
          }

          .rosso {
            color: red;
          }
