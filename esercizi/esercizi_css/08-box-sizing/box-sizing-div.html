Box-sizing: border-box su Div

⏱ 20 minuti · div · box-sizing · border-box · width · padding · border

Descrizione

In questo esercizio applicherai box-sizing: border-box a un <div> per garantire che la larghezza totale dell'elemento sia esattamente 300px, indipendentemente dal padding e dal bordo applicati. Il <div> è l'elemento contenitore più usato nel web e capire il suo box model è fondamentale per costruire layout precisi.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un div:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Box-sizing</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div>Questo div ha una larghezza di 300px, inclusi padding e bordo.</div>
            </body>
          </html>

Passo 2 — Creare il file CSS con border-box

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Il div avrà larghezza totale di 300px, con padding e bordo verde già inclusi:

style.css
          div {
            box-sizing: border-box;
            width: 300px;
            padding: 20px;
            border: 2px solid green;
          }

Passo 3 — Comprendere il calcolo delle dimensioni

Componente Valore Con border-box
Larghezza totale (width) 300px Dimensione esterna fissa
border (× 2 lati) 2px × 2 = 4px Sottratti dall'interno
padding (× 2 lati) 20px × 2 = 40px Sottratti dall'interno
Area contenuto effettiva 300 − 4 − 40 = 256px Spazio disponibile per il testo

Passo 4 — Il box model a confronto

Stesso div con width: 300px ma comportamento diverso secondo il box-sizing:

box-sizing Larghezza contenuto Larghezza totale
content-box (default) 300px 300 + 40 + 4 = 344px
border-box 256px 300px (sempre)

Passo 5 — Personalizzazione avanzata (opzionale)

Aggiungi sfondo e margine per rendere il div visivamente più chiaro:

style.css — Stilizzazione avanzata
          div {
            box-sizing: border-box;
            width: 300px;
            padding: 20px;
            border: 2px solid green;
            background-color: #d1fae5;
            margin: 20px auto;
            font-family: sans-serif;
          }

Proprietà aggiuntive:

  • background-color: #d1fae5; — sfondo verde chiaro per evidenziare il div
  • margin: 20px auto; — centra il div orizzontalmente nella pagina

Risultato atteso

Il div occuperà esattamente 300px di larghezza totale nel browser, con bordo verde e padding che non ne aumentano le dimensioni esterne.

Approfondimenti

Applicare border-box globalmente: nei progetti reali è comune usare il selettore universale per applicare border-box a tutti gli elementi, semplificando il calcolo dei layout:

Regola globale consigliata
          *, *::before, *::after {
            box-sizing: border-box;
          }

Questa regola è inclusa nei CSS reset più diffusi e si trova all'inizio del file style.css nella maggior parte dei progetti moderni.
