Box-sizing: content-box su Link

⏱ 20 minuti · a · box-sizing · content-box · width · padding · border

Descrizione

In questo esercizio applicherai box-sizing: content-box a un link, il valore predefinito del browser. Con content-box, il width specifica solo la larghezza dell'area contenuto: padding e bordo vengono aggiunti al di fuori, aumentando la dimensione totale dell'elemento.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un link:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Box-sizing</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <a href="#">Clicca qui</a>
            </body>
          </html>

Passo 2 — Creare il file CSS con content-box

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Per rendere visibili width e padding su un link è necessario impostarlo come elemento a blocco con display: inline-block:

style.css
          a {
            box-sizing: content-box;
            display: inline-block;
            width: 100px;
            padding: 20px;
            color: black;
            text-decoration: none;
            border: 1px dashed blue;
          }

Passo 3 — Comprendere il calcolo delle dimensioni

Con content-box, il width: 100px misura solo il contenuto. La larghezza totale visibile nel browser è maggiore:

Componente Valore Effetto sulla larghezza totale
Area contenuto (width) 100px Larghezza specificata (solo contenuto)
padding (× 2 lati) 20px × 2 = 40px Aggiunti fuori dal contenuto
border (× 2 lati) 1px × 2 = 2px Aggiunti fuori dal contenuto
Larghezza totale 100 + 40 + 2 = 142px Ciò che occupa realmente nella pagina

Passo 4 — Perché display: inline-block?

Il tag <a> è per default un elemento inline. Gli elementi inline ignorano le proprietà width e height. Impostando display: inline-block si ottiene il meglio dei due mondi:

display Va a capo da solo? Accetta width/height?
inline No No
block Sì (occupa tutta la riga) Sì
inline-block No (resta in linea) Sì

Passo 5 — Personalizzazione avanzata (opzionale)

Sperimenta cambiando il valore di box-sizing a border-box per confrontare:

style.css — Con border-box
          a {
            box-sizing: border-box;
            display: inline-block;
            width: 100px;
            padding: 20px;
            color: black;
            text-decoration: none;
            border: 1px dashed blue;
          }

Con border-box, la larghezza totale rimane 100px e il testo si comprimerà in uno spazio più stretto (100 − 40 − 2 = 58px di contenuto).

Risultato atteso

Il link apparirà con un'area contenuto di 100px e una larghezza totale visibile di 142px (100px + 40px di padding + 2px di bordo). Il bordo è tratteggiato blu e il testo è nero senza sottolineatura.

Approfondimenti

content-box è il default del browser per ragioni storiche: corrisponde al modello originale del CSS. Tuttavia nella pratica moderna quasi tutti i progetti impostano border-box globalmente perché semplifica il calcolo dei layout. Se non scrivi box-sizing nel CSS, il browser usa automaticamente content-box.
