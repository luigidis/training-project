Box-sizing: content-box su Lista

⏱ 20 minuti · ul · li · box-sizing · content-box · height · padding

Descrizione

In questo esercizio applicherai box-sizing: content-box agli elementi di una lista per controllarne l'altezza. Con content-box, il valore di height specifica solo l'altezza dell'area contenuto: padding e bordo vengono aggiunti sopra e sotto, aumentando l'altezza totale visibile.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una lista non ordinata:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Box-sizing</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <ul>
                <li>Elemento 1</li>
                <li>Elemento 2</li>
                <li>Elemento 3</li>
              </ul>
            </body>
          </html>

Passo 2 — Creare il file CSS con content-box

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Con content-box, i 40px di height misurano solo il contenuto: padding e bordo si aggiungono in verticale:

style.css
          li {
            box-sizing: content-box;
            height: 40px;
            padding: 10px;
            list-style-type: none;
            border: 2px solid blue;
          }

Passo 3 — Comprendere il calcolo dell'altezza

Con content-box, l'altezza totale di ogni elemento <li> è la somma di tutte le componenti verticali:

Componente Valore Effetto sull'altezza totale
Area contenuto (height) 40px Altezza specificata (solo contenuto)
padding (top + bottom) 10px × 2 = 20px Aggiunti fuori dal contenuto
border (top + bottom) 2px × 2 = 4px Aggiunti fuori dal contenuto
Altezza totale 40 + 20 + 4 = 64px Altezza visibile nel browser

Passo 4 — Confronto: cosa cambierebbe con border-box

box-sizing Altezza contenuto Altezza totale visibile
content-box 40px 40 + 20 + 4 = 64px
border-box 40 − 20 − 4 = 16px 40px (sempre)

Con border-box e height: 40px, l'area contenuto si riduce a soli 16px, lasciando poco spazio al testo. Con content-box invece, il testo ha 40px garantiti e l'elemento si allarga ulteriormente con padding e bordo.

Passo 5 — Personalizzazione avanzata (opzionale)

Aggiungi stili per rendere gli elementi della lista più visibili:

style.css — Stilizzazione avanzata
          ul {
            padding: 0;
            width: 250px;
          }

          li {
            box-sizing: content-box;
            height: 40px;
            padding: 10px;
            list-style-type: none;
            border: 2px solid blue;
            background-color: #dbeafe;
            margin-bottom: 4px;
            font-family: sans-serif;
          }

Risultato atteso

Ogni elemento della lista avrà un'area contenuto di 40px e un'altezza totale visibile di 64px. Gli elementi avranno bordo blu tratteggiato e nessun marker di lista.

Approfondimenti

Quando usare content-box sull'altezza? È utile quando vuoi garantire che il testo abbia sempre una certa altezza minima di respiro, indipendentemente dal padding decorativo. Se vuoi invece che l'elemento abbia un'altezza fissa e precisa (ad esempio per elementi di un menù o di una barra), border-box è la scelta più prevedibile.
