Box-sizing: content-box con Bordo su Link

⏱ 20 minuti · a · box-sizing · content-box · width · padding · border

Descrizione

In questo esercizio applicherai box-sizing: content-box a un link con width: 120px. Rispetto all'esercizio Box-sizing #2, qui il concetto da osservare è l'effetto del bordo sulla larghezza totale: con content-box, anche il bordo si aggiunge al di fuori del width specificato, allargando ulteriormente l'elemento.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un link:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Box-sizing</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <a href="#">Clicca qui</a>
            </body>
          </html>

Passo 2 — Creare il file CSS con content-box

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Ricorda che per applicare width a un link serve display: inline-block:

style.css
          a {
            box-sizing: content-box;
            display: inline-block;
            width: 120px;
            padding: 20px;
            color: black;
            text-decoration: none;
            border: 1px dashed blue;
          }

Passo 3 — Comprendere il calcolo completo

Con content-box ogni componente del box model si somma esternamente. La larghezza totale del link è:

Componente Valore Effetto sulla larghezza totale
Area contenuto (width) 120px Base di partenza
padding (× 2 lati) 20px × 2 = 40px Aggiunti all'esterno
border (× 2 lati) 1px × 2 = 2px Aggiunti all'esterno
Larghezza totale 120 + 40 + 2 = 162px Dimensione reale nel browser

Passo 4 — Riepilogo finale: content-box vs border-box

Dopo aver completato tutti gli esercizi della sezione Box-sizing, ecco la differenza fondamentale tra i due valori, applicata al link di questo esercizio:

box-sizing width specifica Larghezza contenuto Larghezza totale
content-box Solo il contenuto 120px 162px
border-box Tutto (contenuto + padding + border) 120 − 40 − 2 = 78px 120px

Passo 5 — Personalizzazione avanzata (opzionale)

Metti a confronto i due comportamenti nella stessa pagina aggiungendo un secondo link:

index.html — Due link a confronto
          <a href="#" class="content">content-box (162px)</a>
          <a href="#" class="border">border-box (120px)</a>
style.css — Confronto visivo
          a {
            display: block;
            width: 120px;
            padding: 20px;
            color: black;
            text-decoration: none;
            border: 1px dashed blue;
            margin-bottom: 10px;
          }

          a.content {
            box-sizing: content-box;
            background-color: #fee2e2;
          }

          a.border {
            box-sizing: border-box;
            background-color: #d1fae5;
          }

Il link rosso sarà visibilmente più largo del link verde, pur avendo lo stesso width: 120px.

Risultato atteso

Il link avrà un'area contenuto di 120px e una larghezza totale di 162px, con bordo tratteggiato blu, padding di 20px e testo nero senza sottolineatura.

Approfondimenti

Quando si nota di più la differenza? In layout con colonne affiancate (es. Flexbox o Grid), usare content-box con padding e border può far "traboccare" gli elementi oltre il loro contenitore. Questo è il motivo principale per cui molti developer iniziano ogni progetto con la regola globale * { box-sizing: border-box; }.
