Box-sizing: border-box su Titolo

⏱ 20 minuti · h1 · box-sizing · border-box · height · padding · border

Descrizione

In questo esercizio applicherai box-sizing: border-box a un titolo <h1> per controllarne l'altezza in modo preciso. Con border-box, il valore di height: 80px rappresenta l'altezza totale dell'elemento: padding e bordo sono già inclusi e non aggiungono spazio extra all'esterno.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un titolo:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Box-sizing</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <h1>Questo titolo ha un'altezza di 80px, incluso il padding.</h1>
            </body>
          </html>

Passo 2 — Creare il file CSS con border-box

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Il titolo avrà un'altezza totale di 80px con padding e bordo tratteggiato inclusi:

style.css
          h1 {
            box-sizing: border-box;
            height: 80px;
            padding: 10px;
            border: 1px dashed black;
          }

Passo 3 — Comprendere il calcolo dell'altezza

Con border-box, l'altezza totale è sempre 80px. Padding e bordo si "mangiano" spazio dall'interno, riducendo l'area disponibile per il testo:

Componente Valore Con border-box
Altezza totale (height) 80px Dimensione esterna fissa
border (top + bottom) 1px × 2 = 2px Sottratti dall'interno
padding (top + bottom) 10px × 2 = 20px Sottratti dall'interno
Area contenuto effettiva 80 − 2 − 20 = 58px Spazio disponibile per il testo

Passo 4 — Confronto con content-box

box-sizing Altezza contenuto Altezza totale visibile
content-box (default) 80px 80 + 20 + 2 = 102px
border-box 58px 80px (sempre)

Se vuoi che il titolo occupi esattamente 80px nella pagina (utile in header o barre di navigazione), border-box è la scelta corretta. Con content-box il titolo supererebbe gli 80px a causa di padding e bordo.

Passo 5 — Personalizzazione avanzata (opzionale)

Prova ad allineare verticalmente il testo al centro dell'altezza fissa usando line-height:

style.css — Stilizzazione avanzata
          h1 {
            box-sizing: border-box;
            height: 80px;
            padding: 0 20px;
            border: 1px dashed black;
            line-height: 80px;
            font-size: 1.2rem;
            background-color: #f1f5f9;
          }

Effetti aggiuntivi:

  • line-height: 80px; — allinea il testo verticalmente al centro (uguale all'altezza totale)
  • padding: 0 20px; — padding solo orizzontale, per non disturbare il centramento verticale
  • background-color — evidenzia l'area occupata dal titolo

Risultato atteso

Il titolo occuperà esattamente 80px di altezza totale nella pagina, con bordo tratteggiato nero e padding già inclusi in quella misura.

Approfondimenti

header e barre di navigazione sono i casi d'uso più comuni per height + border-box. Quando si costruisce una navbar alta esattamente 60px, usare border-box garantisce che padding e bordi non "sfondino" l'altezza prevista, evitando calcoli manuali.
