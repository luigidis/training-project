Box-sizing: border-box su Paragrafo

⏱ 20 minuti · p · box-sizing · border-box · width · padding · border

Descrizione

In questo esercizio imparerai a usare la proprietà box-sizing: border-box su un paragrafo. Con questo valore, il width che specifichi rappresenta la larghezza totale dell'elemento: padding e bordo vengono sottratti dall'interno, senza aumentare le dimensioni esterne.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un paragrafo:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Box-sizing</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <p>Questo paragrafo ha una larghezza di 200px, incluso padding e bordo.</p>
            </body>
          </html>

Passo 2 — Creare il file CSS con border-box

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Con border-box, il paragrafo occuperà esattamente 200px in totale, bordo e padding compresi:

style.css
          p {
            box-sizing: border-box;
            width: 200px;
            padding: 20px;
            border: 2px solid red;
          }

Passo 3 — Comprendere il calcolo delle dimensioni

Componente Valore Con border-box
width totale 200px Larghezza totale dell'elemento (fissa)
border (× 2 lati) 2px × 2 = 4px Sottratti dall'interno
padding (× 2 lati) 20px × 2 = 40px Sottratti dall'interno
Area contenuto effettiva 200 − 4 − 40 = 156px Spazio rimasto per il testo

Passo 4 — border-box vs content-box a confronto

Il valore predefinito di box-sizing è content-box. Ecco la differenza con gli stessi valori di width, padding e border:

box-sizing width specifica… Larghezza totale risultante
content-box Solo il contenuto (156px) 156 + 40 + 4 = 200px → no, 156 + 40 + 4 = 200 ✓ ma se width=200: 200 + 40 + 4 = 244px
border-box Contenuto + padding + border Sempre 200px

Con content-box e width: 200px, l'elemento occuperebbe 244px in totale (200 + 40 di padding + 4 di bordo). Con border-box rimane sempre 200px.

Passo 5 — Personalizzazione avanzata (opzionale)

Prova ad aggiungere un secondo paragrafo senza border-box per vedere la differenza visiva:

style.css — Confronto visivo
          p.border-box {
            box-sizing: border-box;
            width: 200px;
            padding: 20px;
            border: 2px solid red;
            background-color: #fee2e2;
            margin-bottom: 10px;
          }

          p.content-box {
            box-sizing: content-box;
            width: 200px;
            padding: 20px;
            border: 2px solid blue;
            background-color: #dbeafe;
          }

Assegna le classi border-box e content-box a due paragrafi nell'HTML: vedrai che il secondo è visibilmente più largo del primo.

Risultato atteso

Il paragrafo avrà una larghezza totale di esattamente 200px, con bordo rosso e padding interni che non ne aumentano le dimensioni esterne.

Approfondimenti

Perché border-box è preferito dai developer? Molti framework CSS (come Bootstrap) applicano box-sizing: border-box a tutti gli elementi con la regola universale * { box-sizing: border-box; }. Questo rende i calcoli delle dimensioni molto più intuitivi: il valore di width corrisponde sempre a ciò che si vede nel browser.
