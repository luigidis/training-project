Margin e Padding su un Link

⏱ 25 minuti · margin · padding · box model · text-decoration

Descrizione

In questo esercizio imparerai la differenza tra margin (margine esterno) e padding (spaziatura interna). Applicherai queste proprietà a un link per capire come influenzano l'aspetto e lo spazio occupato dall'elemento.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un link:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 2</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <a href="#">Clicca qui</a>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare margin e padding

All'interno del file style.css, applica le proprietà margin e padding al link:

style.css
          a {
            margin: 0;
            padding: 15px;
            color: black;
            text-decoration: none;
          }

Spiegazione delle proprietà:

Proprietà Valore Significato
margin 0 Margine esterno (spazio fuori dal bordo dell'elemento) impostato a 0
padding 15px Spaziatura interna (spazio tra il bordo e il contenuto) di 15 pixel
color black Colore del testo nero
text-decoration none Rimuove la sottolineatura del link

Passo 4 — Visualizzare il box model

Per capire meglio l'effetto del padding, aggiungi un colore di sfondo al link:

style.css — Con background
          a {
            margin: 0;
            padding: 15px;
            color: black;
            text-decoration: none;
            background-color: lightblue;
          }

Ora puoi vedere chiaramente come il padding crea uno spazio interno tra il testo "Clicca qui" e il bordo dello sfondo azzurro.

Passo 5 — Sperimentare con il margin

Prova a modificare il valore del margin per vedere la differenza:

style.css — Con margin
          a {
            margin: 20px;
            padding: 15px;
            color: black;
            text-decoration: none;
            background-color: lightblue;
          }

Il margin: 20px; crea uno spazio di 20 pixel attorno all'intero elemento (fuori dallo sfondo azzurro).

Risultato atteso

Con il codice del Passo 4, dovresti vedere:

  • Un link "Clicca qui" senza sottolineatura
  • Sfondo azzurro attorno al testo
  • Spazio di 15px tra il testo e il bordo dello sfondo (padding)
  • Nessuno spazio esterno (margin a 0)

Approfondimenti

Il Box Model CSS:

Ogni elemento HTML può essere visualizzato come una scatola (box) composta da diversi livelli:

  1. Content — Il contenuto dell'elemento (es. il testo)
  2. Padding — Spazio interno tra il contenuto e il bordo
  3. Border — Il bordo dell'elemento
  4. Margin — Spazio esterno tra l'elemento e gli altri elementi
Visualizzazione Box Model
          ┌─────────────────────────────────┐
          │        MARGIN (esterno)         │
          │  ┌───────────────────────────┐  │
          │  │      BORDER (bordo)       │  │

Sintassi margin e padding:

  • margin: 10px; — 10px su tutti i lati
  • margin: 10px 20px; — 10px sopra/sotto, 20px destra/sinistra
  • margin: 10px 20px 15px 25px; — Sopra, Destra, Sotto, Sinistra (senso orario)
  • margin-top: 10px; — Solo il margine superiore

La stessa sintassi vale per il padding.

Differenza pratica:

  • Padding — Aumenta l'area cliccabile del link e lo spazio interno dello sfondo
  • Margin — Crea distanza tra il link e altri elementi vicini
