Margin e Padding con Lista Personalizzata

⏱ 25 minuti · margin · padding · color · list-style

Descrizione

In questo esercizio combinerai le proprietà margin e padding con la stilizzazione dei marker della lista. Creerai una lista con margine esterno, padding interno, e punti di colore rosso per ottenere un aspetto personalizzato.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una lista non ordinata:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 8</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <ul>
                <li>Elemento 1</li>
                <li>Elemento 2</li>
                <li>Elemento 3</li>
              </ul>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare margin, padding e colore ai marker

All'interno del file style.css, applica le proprietà agli elementi li:

style.css
          li {
            margin: 5px;
            padding: 10px;
            color: red;
          }

Spiegazione delle proprietà:

Proprietà Valore Significato
margin 5px Margine esterno di 5 pixel attorno a ogni elemento della lista
padding 10px Spaziatura interna di 10 pixel all'interno di ogni elemento
color red Colore rosso applicato al testo E ai marker (punti) della lista

Nota importante:

La proprietà color applicata a un elemento li cambia sia il colore del testo che il colore del marker (pallino) della lista. Questo è il modo più semplice per colorare i punti della lista.

Passo 4 — Separare il colore del testo dai marker

Se vuoi che i punti siano rossi ma il testo sia di un altro colore, puoi usare un elemento <span> all'interno del li:

HTML — Con span per separare i colori
          <ul>
            <li><span>Elemento 1</span></li>
            <li><span>Elemento 2</span></li>
            <li><span>Elemento 3</span></li>
          </ul>
CSS — Colori separati
          li {
            margin: 5px;
            padding: 10px;
            color: red;  /* Colore dei marker */
          }

          li span {
            color: black;  /* Colore del testo */
          }

Passo 5 — Visualizzare l'effetto completo

Per vedere chiaramente l'effetto di margin e padding, aggiungi uno sfondo:

style.css — Con background
          li {
            margin: 5px;
            padding: 10px;
            color: red;
            background-color: lightyellow;
          }

          li span {
            color: black;
          }

Ora puoi vedere chiaramente:

  • Il margin di 5px crea spazio tra un elemento e l'altro (fuori dallo sfondo giallo)
  • Il padding di 10px crea spazio interno (dentro lo sfondo giallo)
  • I punti sono rossi, il testo è nero

Risultato atteso

Con il codice del Passo 3, dovresti vedere:

  • Tre elementi di lista con punti rossi
  • Testo rosso in ogni elemento
  • Spazio esterno di 5px tra gli elementi (margin)
  • Spazio interno di 10px all'interno di ogni elemento (padding)

Con il codice del Passo 5:

  • Punti rossi ma testo nero
  • Sfondo giallo chiaro che mostra chiaramente l'area di padding
  • Spazio visibile tra gli elementi creato dal margin

Approfondimenti

Come funziona il colore dei marker:

I marker delle liste (pallini, numeri, ecc.) ereditano il colore dalla proprietà color dell'elemento li. Per questo motivo, quando imposti color: red; su un li, sia il marker che il testo diventano rossi.

Metodi alternativi per stilizzare i marker:

CSS — Marker personalizzato con ::marker
          li {
            margin: 5px;
            padding: 10px;
          }

          li::marker {
            color: red;
            font-size: 20px;
          }

La pseudo-elemento ::marker (supportato nei browser moderni) permette di stilizzare direttamente il marker senza influenzare il testo.

Tipi di marker disponibili:

  • list-style-type: disc; — Pallino pieno (default)
  • list-style-type: circle; — Pallino vuoto
  • list-style-type: square; — Quadrato
  • list-style-type: decimal; — Numeri (1, 2, 3...)
  • list-style-type: lower-alpha; — Lettere minuscole (a, b, c...)

Combinazione pratica:

CSS — Lista stilizzata completa
          ul {
            list-style-type: square;
          }

          li {
            margin: 8px 0;
            padding: 12px 15px;
            color: #c00;
            background-color: #ffe;
            border-left: 3px solid #c00;
          }

          li span {
            color: #333;
          }
