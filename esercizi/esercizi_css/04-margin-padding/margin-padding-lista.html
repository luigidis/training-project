Margin e Padding su Lista

⏱ 20 minuti · margin · padding · liste · list-style-type

Descrizione

In questo esercizio applicherai le proprietà margin e padding agli elementi di una lista non ordinata. Imparerai come controllare lo spazio interno ed esterno degli elementi per creare una lista ben strutturata e leggibile.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una lista non ordinata:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 4</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <ul>
                <li>Elemento 1</li>
                <li>Elemento 2</li>
                <li>Elemento 3</li>
              </ul>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML.

Passo 3 — Applicare margin e padding agli elementi della lista

All'interno del file style.css, applica le proprietà agli elementi li:

style.css
          li {
            margin: 0;
            padding: 10px;
            list-style-type: none;
          }

Spiegazione delle proprietà:

Proprietà Valore Significato
margin 0 Nessun margine esterno tra gli elementi della lista
padding 10px Spaziatura interna di 10 pixel all'interno di ogni elemento
list-style-type none Rimuove i pallini/marker della lista

Passo 4 — Visualizzare l'effetto con uno sfondo

Per rendere più chiaro l'effetto del padding, aggiungi un colore di sfondo:

style.css — Con background
          li {
            margin: 0;
            padding: 10px;
            list-style-type: none;
            background-color: lightcoral;
          }

Ora puoi vedere come il padding crea uno spazio interno tra il testo e il bordo dello sfondo colorato di ogni elemento della lista.

Passo 5 — Aggiungere spazio tra gli elementi (opzionale)

Se vuoi creare spazio tra un elemento e l'altro, usa il margin-bottom:

style.css — Con margin-bottom
          li {
            margin: 0;
            margin-bottom: 10px;
            padding: 10px;
            list-style-type: none;
            background-color: lightcoral;
          }

Il margin-bottom: 10px; crea uno spazio di 10 pixel sotto ogni elemento della lista, separandoli visivamente.

Risultato atteso

Con il codice del Passo 4, dovresti vedere:

  • Tre elementi di lista senza i pallini
  • Ogni elemento con sfondo color coral
  • Spazio interno di 10px tra il testo e il bordo dello sfondo (padding)
  • Nessuno spazio tra gli elementi (margin a 0)

Con il codice del Passo 5:

  • Gli stessi elementi, ma con 10px di spazio tra un elemento e l'altro

Approfondimenti

Margin vs Padding nelle liste:

  • Padding: Aumenta lo spazio interno di ogni elemento, rendendo l'area colorata più grande
  • Margin: Crea distanza tra gli elementi della lista, separandoli visivamente

Proprietà margin specifiche per direzione:

Proprietà Descrizione
margin-top Margine solo in alto
margin-right Margine solo a destra
margin-bottom Margine solo in basso
margin-left Margine solo a sinistra

Le stesse proprietà esistono per il padding: padding-top, padding-right, ecc.

Consiglio pratico:

Quando si stilizzano liste, è comune usare padding per rendere gli elementi più grandi e facili da cliccare (utile per menu di navigazione) e margin per separarli visivamente.

Esempio di lista navigazione:

CSS — Stile menu navigazione
          li {
            margin: 0;
            margin-bottom: 5px;
            padding: 15px 20px;
            list-style-type: none;
            background-color: #333;
            color: white;
            cursor: pointer;
          }

          li:hover {
            background-color: #555;
          }
