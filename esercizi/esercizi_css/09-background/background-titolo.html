Background Image su Titolo

⏱ 20 minuti · h1 · background-image · background-repeat · repeat-x · padding · color

Descrizione

In questo esercizio imparerai a impostare un'immagine di sfondo su un titolo h1 usando la proprietà background-image, e a farla ripetere solo orizzontalmente con background-repeat: repeat-x. Aggiungerai anche del padding per creare spazio intorno al testo.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html con un titolo e il collegamento al file CSS esterno style.css:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Background Titolo</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <h1>Questo è un titolo con un'immagine di sfondo ripetuta orizzontalmente.</h1>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella. Imposta l'immagine di sfondo sull'elemento h1 e usa repeat-x per farla ripetere solo in orizzontale:

style.css
          h1 {
            background-image: url("sfondo-titolo.jpg");
            background-repeat: repeat-x;
            padding: 20px;
            color: white;
          }

Passo 3 — I valori di background-repeat

La proprietà background-repeat controlla se e come l'immagine di sfondo si ripete. Questi sono i valori principali:

Valore Comportamento
repeat L'immagine si ripete sia in orizzontale che in verticale (valore predefinito)
repeat-x L'immagine si ripete solo orizzontalmente
repeat-y L'immagine si ripete solo verticalmente
no-repeat L'immagine appare una sola volta, senza ripetizioni

Passo 4 — Perché il padding è importante

Senza padding, il testo del titolo si sovrappone al bordo dell'immagine di sfondo, risultando difficile da leggere. Con padding: 20px crei uno spazio interno che separa il testo dai bordi dell'elemento, migliorando la leggibilità.

La proprietà color: white rende il testo leggibile su sfondi scuri. Adatta il colore in base all'immagine che utilizzi.

Passo 5 — Aggiungere un'immagine di test

Per testare l'esercizio avrai bisogno di un file immagine chiamato sfondo-titolo.jpg nella stessa cartella dell'HTML. Usa un'immagine più stretta della larghezza del titolo per vedere l'effetto di ripetizione.

Per verificare la struttura senza un'immagine reale, puoi usare un gradiente CSS come sfondo:

style.css — versione con gradiente di test
          h1 {
            background-image: linear-gradient(to right, #1d4ed8, #7c3aed);
            padding: 20px;
            color: white;
          }

Risultato atteso

Il titolo mostrerà l'immagine di sfondo ripetuta orizzontalmente per tutta la sua larghezza. Il testo bianco sarà leggibile grazie al padding e al colore.

Approfondimenti

Differenza tra repeat-x e repeat: con repeat l'immagine riempie completamente l'elemento sia in larghezza che in altezza. Con repeat-x si ripete solo orizzontalmente e rimane ancorata al bordo superiore. Questo la rende ideale per effetti come barre decorative o header con texture.
