Background Image su Colonne

⏱ 25 minuti · div · background-image · background-repeat · float · box-sizing

Descrizione

In questo esercizio creerai una sezione divisa in tre colonne affiancate usando tre div. Ogni colonna avrà un'immagine di sfondo diversa, ripetuta orizzontalmente con background-repeat: repeat-x. Utilizzerai anche float: left per affiancare i div e box-sizing: border-box per gestirne le dimensioni con precisione.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html. Inserisci tre div, ognuno con due classi: una comune e una specifica per la colonna. Collega il file CSS esterno style.css:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Background Colonne</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <div class="colonna colonna-1"></div>
              <div class="colonna colonna-2"></div>
              <div class="colonna colonna-3"></div>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella. Prima definisci gli stili condivisi da tutte le colonne con la classe .colonna, poi aggiungi l'immagine specifica per ciascuna:

style.css
          .colonna {
            height: 200px;
            width: 30%;
            float: left;
            box-sizing: border-box;
            background-repeat: repeat-x;
          }

          .colonna-1 {
            background-image: url("colonna1.jpg");
          }

          .colonna-2 {
            background-image: url("colonna2.jpg");
          }

          .colonna-3 {
            background-image: url("colonna3.jpg");
          }

Passo 3 — Capire ogni proprietà

Proprietà Valore usato Effetto
width: 30% 30% Ogni colonna occupa il 30% della larghezza disponibile
height: 200px 200px Altezza fissa: necessaria perché i div sono vuoti
float: left left Affianca i div orizzontalmente
box-sizing: border-box border-box Il 30% include eventuali padding e bordi
background-repeat: repeat-x repeat-x L'immagine si ripete solo orizzontalmente
background-image url("...") Immagine diversa per ciascuna colonna

Passo 4 — Perché l'altezza è necessaria

I tre div nell'HTML sono vuoti: non contengono testo né altri elementi. Un elemento vuoto ha altezza zero di default, quindi non sarebbe visibile. La regola height: 200px garantisce che le colonne abbiano una dimensione verticale sufficiente a mostrare le immagini di sfondo.

Passo 5 — Aggiungere le immagini di test

Per testare l'esercizio avrai bisogno di tre file immagine nella stessa cartella dell'HTML, chiamati colonna1.jpg, colonna2.jpg e colonna3.jpg. Puoi usare qualsiasi immagine di larghezza inferiore alla colonna per vedere l'effetto di ripetizione.

Per verificare la struttura senza immagini reali, puoi usare colori di sfondo:

style.css — versione con colori di test
          .colonna-1 { background-color: #fecaca; }
          .colonna-2 { background-color: #bbf7d0; }
          .colonna-3 { background-color: #bfdbfe; }

Risultato atteso

Tre colonne affiancate, ciascuna larga il 30% della pagina e alta 200px. Ognuna mostra un'immagine di sfondo diversa, ripetuta orizzontalmente.

Approfondimenti

Nota su float: questo metodo di layout era molto comune prima dell'introduzione di Flexbox e Grid. Quando si usa float, il contenitore padre può "collassare" e non avvolgere i figli. Per evitarlo si aggiunge spesso un elemento vuoto con clear: both dopo le colonne, oppure si usa la tecnica del clearfix.
