Background Image su Link

⏱ 20 minuti · a · background-image · background-repeat · background-size · padding

Descrizione

In questo esercizio imparerai a usare la proprietà background-image per inserire un'immagine di sfondo all'interno di un link. Vedremo anche come controllarne la ripetizione, le dimensioni e come usare il padding per fare spazio all'icona.

Passo 1 — Creare la struttura HTML

Crea un nuovo file chiamato index.html. Inserisci un link e collega il file CSS esterno style.css:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Background Link</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <a href="#">Questo link ha un'icona come sfondo.</a>
            </body>
          </html>

Passo 2 — Creare il file CSS

Crea un nuovo file chiamato style.css nella stessa cartella. Usa background-image per aggiungere un'icona come sfondo al link, e il padding-left per fare spazio all'immagine a sinistra del testo:

style.css
          a {
            background-image: url("icona.png");
            background-repeat: no-repeat;
            background-size: 30px 30px;
            padding: 5px 5px 5px 35px;
            color: black;
            text-decoration: none;
          }

Passo 3 — Capire ogni proprietà

Proprietà Valore usato Effetto
background-image url("icona.png") Imposta l'immagine di sfondo
background-repeat no-repeat L'immagine appare una volta sola, senza ripetersi
background-size 30px 30px Ridimensiona l'immagine a 30×30 pixel
padding 5px 5px 5px 35px Crea spazio a sinistra per non coprire l'icona con il testo
text-decoration none Rimuove la sottolineatura del link

Passo 4 — Aggiungere un'immagine di test

Per testare l'esercizio hai bisogno di un file immagine chiamato icona.png nella stessa cartella del file HTML. Puoi usare qualsiasi icona di piccole dimensioni (ad esempio scaricarne una gratuita da una libreria di icone).

Se preferisci testare senza un file esterno, puoi usare un colore al posto dell'immagine e verificare il comportamento del padding:

style.css — versione con colore di test
          a {
            background-color: #dbeafe;
            padding: 5px 5px 5px 35px;
            color: black;
            text-decoration: none;
          }

Risultato atteso

Il link mostrerà un'icona a sinistra del testo. L'icona non si ripete, ha dimensioni fisse di 30×30px, e il testo è spostato a destra per non sovrapporsi all'immagine.

Approfondimenti

Perché usare background-image invece di un tag <img>? Le immagini di sfondo sono considerate decorative: non fanno parte del contenuto semantico della pagina. Per questo si usano via CSS e non nell'HTML. Un'icona puramente visuale accanto a un testo è il caso d'uso perfetto per background-image.
