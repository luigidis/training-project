Pseudo-elemento ::before su Link

⏱ 15 minuti · a · ::before · content · margin-right · pseudo-elementi

Descrizione

In questo esercizio userai il pseudo-elemento ::before per aggiungere automaticamente un'icona (freccia) prima del testo di ogni link. Scoprirai come la proprietà content possa contenere non solo testo, ma anche caratteri Unicode, aprendo molte possibilità decorative senza librerie di icone esterne.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un link:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-elementi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <a href="#">Link esterno</a>
            </body>
          </html>

Passo 2 — Creare il file CSS con ::before

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Usa la proprietà content con il codice Unicode della freccia (➔):

style.css
          a::before {
            content: "\2794";
            margin-right: 5px;
          }

Il valore "\2794" è il codice Unicode del carattere ➔ (freccia destra pesante). In CSS i codici Unicode si scrivono con il prefisso \ seguito dal codice esadecimale.

Passo 3 — Caratteri Unicode utili per le icone

Carattere Codice CSS Descrizione
➔ "\2794" Freccia destra pesante
→ "\2192" Freccia destra semplice
★ "\2605" Stella piena
✓ "\2713" Segno di spunta
• "\2022" Pallino (bullet)
» "\00BB" Doppia parentesi angolare destra

Passo 4 — Personalizzazione avanzata (opzionale)

Combina il pseudo-elemento con altri stili per creare un link più curato:

style.css — Stilizzazione avanzata
          a {
            font-size: 1rem;
            text-decoration: none;
            color: steelblue;
          }

          a::before {
            content: "\2794";
            margin-right: 6px;
            color: orange;
            font-size: 0.9em;
          }

          a:hover::before {
            color: red;
          }

Effetti aggiuntivi:

  • color sul ::before — l'icona può avere un colore diverso dal testo
  • font-size: 0.9em; — l'icona è leggermente più piccola del testo
  • a:hover::before — cambia il colore dell'icona al passaggio del mouse (pseudo-classe + pseudo-elemento combinati!)

Risultato atteso

Il link apparirà con la freccia ➔ automaticamente prima del testo, aggiunta tramite CSS senza modificare l'HTML.

Approfondimenti

In alternativa ai codici Unicode, puoi inserire il carattere direttamente come stringa nella proprietà content:

Sintassi alternativa
          a::before {
            content: "➔ ";
          }

Entrambe le sintassi producono lo stesso risultato. I codici Unicode sono preferibili quando si vuole evitare problemi di encoding del file.
