Pseudo-elemento ::before su Paragrafo

⏱ 20 minuti · p · ::before · position · content · pseudo-elementi

Descrizione

In questo esercizio imparerai a usare il pseudo-elemento CSS ::before per aggiungere uno sfondo colorato a un paragrafo. A differenza delle pseudo-classi, i pseudo-elementi inseriscono contenuto virtuale nel documento senza modificare l'HTML. Il trucco di questo esercizio sta nel combinare position: absolute sul ::before con position: relative sul paragrafo padre.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un paragrafo di testo:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-elementi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <p>Questo è un esempio di testo con sfondo colorato.</p>
            </body>
          </html>

Passo 2 — Creare il file CSS con ::before

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Il paragrafo deve avere position: relative per contenere il ::before posizionato in modo assoluto:

style.css
          p {
            position: relative;
          }

          p::before {
            content: "";
            display: block;
            width: 100%;
            height: 100%;
            background-color: yellow;
            position: absolute;
            z-index: -1;
          }

Passo 3 — Comprendere le proprietà usate

Proprietà Valore Significato
content "" Obbligatoria per i pseudo-elementi. Stringa vuota: nessun testo, solo l'elemento visivo
display: block block Rende il pseudo-elemento un blocco con dimensioni proprie
width / height 100% Il pseudo-elemento occupa tutta la larghezza e altezza del paragrafo padre
position: absolute absolute Posiziona il pseudo-elemento rispetto al padre (che ha position: relative)
z-index: -1 -1 Mette il pseudo-elemento dietro al testo del paragrafo

Passo 4 — Personalizzazione avanzata (opzionale)

Prova a variare colore e forma dello sfondo per effetti decorativi diversi:

style.css — Stilizzazione avanzata
          p {
            position: relative;
            padding: 12px 16px;
            font-size: 1.1rem;
          }

          p::before {
            content: "";
            display: block;
            width: 100%;
            height: 100%;
            background-color: #fffacd;
            border-left: 4px solid gold;
            border-radius: 4px;
            position: absolute;
            top: 0;
            left: 0;
            z-index: -1;
          }

Proprietà aggiuntive:

  • top: 0; left: 0; — ancora il pseudo-elemento all'angolo in alto a sinistra del padre
  • border-left — aggiunge una barra colorata a sinistra (stile nota/citazione)
  • border-radius — angoli arrotondati per lo sfondo

Risultato atteso

Il paragrafo apparirà con uno sfondo giallo dietro al testo, creato esclusivamente tramite CSS senza aggiungere elementi HTML aggiuntivi.

Approfondimenti

Differenza tra pseudo-classi e pseudo-elementi:

  • Pseudo-classi (:hover, :active…) — reagiscono a uno stato dell'elemento
  • Pseudo-elementi (::before, ::after…) — inseriscono contenuto virtuale nel documento

I pseudo-elementi usano la doppia due-punti (::) nella sintassi moderna CSS3, mentre la sintassi legacy con singola due-punti (:before) è ancora accettata dai browser per compatibilità.
