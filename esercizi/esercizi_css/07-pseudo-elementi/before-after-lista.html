Pseudo-elementi ::before e ::after su Lista

⏱ 20 minuti · ul · li · ::before · ::after · content · pseudo-elementi

Descrizione

In questo esercizio combinerai i due pseudo-elementi ::before e ::after su una lista non ordinata per aggiungere parentesi graffe attorno a ogni elemento. Questo esercizio riassume tutto quello che hai imparato sui pseudo-elementi: vedrai come i due lavorano insieme, uno prima e uno dopo il contenuto di ogni <li>.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una lista non ordinata:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-elementi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <ul>
                <li>Elemento 1</li>
                <li>Elemento 2</li>
                <li>Elemento 3</li>
                <li>Elemento 4</li>
              </ul>
            </body>
          </html>

Passo 2 — Creare il file CSS con ::before e ::after

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Definisci due regole separate per i due pseudo-elementi:

style.css
          li::before {
            content: "{ ";
          }

          li::after {
            content: " }";
          }

Ogni elemento della lista verrà visualizzato come: { Elemento 1 }, { Elemento 2 }, ecc. Le parentesi graffe sono aggiunte esclusivamente tramite CSS.

Passo 3 — Comprendere ::before e ::after a confronto

Pseudo-elemento Dove si inserisce Valore content usato
::before Prima del contenuto testuale dell'elemento "{ " (parentesi graffa aperta + spazio)
::after Dopo il contenuto testuale dell'elemento " }" (spazio + parentesi graffa chiusa)

Nota gli spazi nella stringa content: "{ " ha uno spazio dopo la parentesi, mentre " }" ha uno spazio prima. Questo crea la spaziatura visiva tra la parentesi e il testo.

Passo 4 — Personalizzazione avanzata (opzionale)

Aggiungi stile alle parentesi graffe per farle risaltare rispetto al testo:

style.css — Stilizzazione avanzata
          ul {
            list-style: none;
            padding: 0;
          }

          li {
            font-family: monospace;
            font-size: 1.1rem;
            margin: 6px 0;
            color: #333;
          }

          li::before {
            content: "{ ";
            color: steelblue;
            font-weight: bold;
          }

          li::after {
            content: " }";
            color: steelblue;
            font-weight: bold;
          }

Effetti aggiuntivi:

  • font-family: monospace; — font a larghezza fissa (stile codice) che valorizza le parentesi graffe
  • color: steelblue; — le parentesi hanno un colore diverso dal testo della lista
  • font-weight: bold; — parentesi in grassetto per maggiore visibilità

Risultato atteso

Ogni elemento della lista apparirà nel formato:

  • { Elemento 1 }
  • { Elemento 2 }
  • { Elemento 3 }
  • { Elemento 4 }

Le parentesi graffe sono aggiunte automaticamente tramite CSS, senza modificare l'HTML.

Approfondimenti

Altri usi pratici di ::before e ::after:

  • Aggiungere virgolette automatiche ai tag <blockquote>
  • Inserire icone decorative prima dei titoli di sezione
  • Creare tooltip o badge informativi puri in CSS
  • Aggiungere etichette di tipo ("PDF", "Esterno") ai link

La combinazione di ::before e ::after sullo stesso elemento permette di creare cornici, decorazioni doppie e pattern tipografici complessi, tutto senza aggiungere una sola riga di HTML in più.
