Pseudo-elemento ::after su Titolo

⏱ 15 minuti · h1 · ::after · border-bottom · content · pseudo-elementi

Descrizione

In questo esercizio userai il pseudo-elemento CSS ::after per aggiungere automaticamente una linea decorativa sotto ogni titolo <h1>. Questo è uno degli utilizzi più pratici dei pseudo-elementi: decorare elementi HTML senza aggiungere tag extra nell'HTML.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un titolo:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-elementi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <h1>Titolo</h1>
            </body>
          </html>

Passo 2 — Creare il file CSS con ::after

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Il pseudo-elemento ::after viene inserito dopo il contenuto del titolo, e lo trasformiamo in un blocco con un bordo inferiore:

style.css
          h1::after {
            content: "";
            display: block;
            border-bottom: 1px solid black;
          }

Passo 3 — Comprendere le proprietà usate

Proprietà Valore Significato
content "" Obbligatoria per i pseudo-elementi. Stringa vuota: l'elemento è visivo, non testuale
display: block block Il pseudo-elemento occupa tutta la larghezza disponibile, permettendo al bordo di estendersi
border-bottom 1px solid black Disegna una linea nera solida di 1 pixel sotto il pseudo-elemento

Perché funziona? Il ::after viene inserito come ultimo figlio virtuale dell'<h1>. Con display: block si estende per tutta la larghezza del titolo, e il border-bottom crea la linea visiva.

Passo 4 — Personalizzazione avanzata (opzionale)

Prova a rendere la linea più decorativa con larghezza, colore e margine personalizzati:

style.css — Stilizzazione avanzata
          h1 {
            display: inline-block;
          }

          h1::after {
            content: "";
            display: block;
            border-bottom: 3px solid steelblue;
            margin-top: 6px;
            width: 60%;
          }

Effetti ottenibili:

  • border-bottom: 3px solid steelblue; — linea più spessa e colorata
  • margin-top: 6px; — spazio tra il testo e la linea
  • width: 60%; — linea più corta del titolo (effetto decorativo)
  • display: inline-block sull'h1 — fa sì che la larghezza si adatti al testo

Risultato atteso

Sotto il titolo apparirà una linea nera che si estende per tutta la sua larghezza, aggiunta automaticamente tramite CSS senza modificare l'HTML.

Approfondimenti

::before vs ::after — quando usarli?

  • ::before — inserisce il contenuto virtuale prima del contenuto dell'elemento
  • ::after — inserisce il contenuto virtuale dopo il contenuto dell'elemento

Entrambi sono figli virtuali dell'elemento a cui sono applicati e possono ricevere qualsiasi proprietà CSS (colori, dimensioni, posizionamento, ecc.). La proprietà content è sempre obbligatoria, anche se vuota.
