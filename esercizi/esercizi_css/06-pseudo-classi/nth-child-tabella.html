Pseudo-classe :nth-child su Tabella

⏱ 20 minuti · table · tr · :nth-child · odd · pseudo-classi

Descrizione

In questo esercizio userai la pseudo-classe :nth-child per colorare alternativamente le righe di una tabella HTML. Questo effetto, chiamato zebra striping, migliora la leggibilità delle tabelle con molte righe ed è uno degli utilizzi più comuni delle pseudo-classi strutturali in CSS.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una tabella contenente almeno cinque righe:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-classi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <table>
                <tr><td>Riga 1</td></tr>
                <tr><td>Riga 2</td></tr>
                <tr><td>Riga 3</td></tr>
                <tr><td>Riga 4</td></tr>
                <tr><td>Riga 5</td></tr>
              </table>
            </body>
          </html>

Passo 2 — Creare il file CSS con :nth-child(odd)

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. La regola seguente seleziona le righe dispari (1ª, 3ª, 5ª...) e le colora di grigio chiaro:

style.css
          tr:nth-child(odd) {
            background-color: lightgrey;
          }

Passo 3 — Comprendere :nth-child

Valore Seleziona Esempio
odd Elementi in posizione dispari (1, 3, 5…) tr:nth-child(odd)
even Elementi in posizione pari (2, 4, 6…) tr:nth-child(even)
3 Esattamente il 3° elemento tr:nth-child(3)
2n Ogni 2° elemento (equivale a even) tr:nth-child(2n)
3n+1 1°, 4°, 7°, 10°… (ogni 3, partendo dal 1°) tr:nth-child(3n+1)

Passo 4 — Personalizzazione avanzata (opzionale)

Aggiungi stili completi alla tabella per un aspetto più professionale:

style.css — Stilizzazione avanzata
          table {
            border-collapse: collapse;
            width: 400px;
          }

          td {
            padding: 10px 16px;
            border: 1px solid #ccc;
          }

          tr:nth-child(odd) {
            background-color: lightgrey;
          }

          tr:hover {
            background-color: #d0e8ff;
          }

Proprietà aggiuntive:

  • border-collapse: collapse; — unisce i bordi adiacenti delle celle
  • padding su td — spazio interno nelle celle
  • tr:hover — evidenzia la riga al passaggio del cursore (combina due pseudo-classi!)

Risultato atteso

La tabella mostrerà:

  • Righe dispari (1ª, 3ª, 5ª…) con sfondo grigio chiaro
  • Righe pari (2ª, 4ª…) con sfondo bianco (colore predefinito)
  • Alternanza che rende la lettura molto più agevole

Approfondimenti

:nth-child vs :nth-of-type — :nth-child conta tutti i figli dell'elemento padre indipendentemente dal tipo di tag. :nth-of-type invece conta solo gli elementi dello stesso tipo (ad esempio solo i <tr>). In una tabella semplice i due si comportano allo stesso modo, ma in layout complessi la differenza diventa importante.
