Pseudo-classi :hover e :active su Lista

⏱ 20 minuti · ul · li · :hover · :active · pseudo-classi

Descrizione

In questo esercizio combinerai le pseudo-classi :hover e :active su una lista non ordinata (<ul>). Rispetto all'esercizio Pseudo-classi #1, qui aggiungerai anche la reazione al clic: gli elementi diventeranno blu al passaggio del mouse e arancioni nel momento del clic.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una lista non ordinata:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-classi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <ul>
                <li>Elemento 1</li>
                <li>Elemento 2</li>
                <li>Elemento 3</li>
                <li>Elemento 4</li>
              </ul>
            </body>
          </html>

Passo 2 — Creare il file CSS con :hover e :active

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Gli elementi della lista devono diventare blu al hover e arancioni al clic:

style.css
          li:hover {
            color: blue;
          }

          li:active {
            color: orange;
          }

Passo 3 — Confronto con l'esercizio Pseudo-classi #1

Esercizio :hover :active
Pseudo-classi #1 color: red non presente
Pseudo-classi #4 (questo) color: blue color: orange

Aggiungendo :active si ottiene un secondo livello di feedback visivo: l'utente vede prima il cambio di colore al passaggio del cursore, poi un ulteriore cambio nel momento esatto del clic.

Passo 4 — Personalizzazione avanzata (opzionale)

Arricchisci la lista con uno stile base e aggiungi effetti di transizione:

style.css — Stilizzazione avanzata
          ul {
            list-style: none;
            padding: 0;
          }

          li {
            padding: 8px 14px;
            margin: 4px 0;
            background-color: #f0f4ff;
            border-radius: 4px;
            cursor: pointer;
            transition: color 0.15s, background-color 0.15s;
          }

          li:hover {
            color: blue;
            background-color: #dce8ff;
          }

          li:active {
            color: orange;
            background-color: #fff3dc;
          }

Risultato atteso

Gli elementi della lista si comporteranno così:

  • Stato normale: testo scuro su sfondo standard
  • Al passaggio del mouse (:hover): testo blu
  • Durante il clic (:active): testo arancione

Approfondimenti

Perché :active è così breve? La pseudo-classe :active rimane attiva solo per il tempo in cui il tasto del mouse resta premuto. Su dispositivi touch, corrisponde al momento del tocco sullo schermo. È ideale per simulare l'effetto "pressione" tipico dei pulsanti fisici.
