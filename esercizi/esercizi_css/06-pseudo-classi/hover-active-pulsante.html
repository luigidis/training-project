Pseudo-classi :hover e :active su Pulsante

⏱ 15 minuti · button · :hover · :active · pseudo-classi

Descrizione

In questo esercizio applicherai due pseudo-classi CSS a un pulsante (<button>): :hover per cambiarne il colore al passaggio del mouse, e :active per cambiarlo di nuovo nel momento in cui viene cliccato. Imparerai così a distinguere due momenti diversi dell'interazione utente.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un pulsante:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-classi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <button>Clicca qui</button>
            </body>
          </html>

Passo 2 — Creare il file CSS con :hover e :active

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Definisci due regole separate: una per il passaggio del mouse e una per il clic:

style.css
          button:hover {
            background-color: blue;
          }

          button:active {
            background-color: red;
          }

Passo 3 — Comprendere :hover e :active a confronto

Pseudo-classe Quando si attiva Durata
:hover Quando il cursore del mouse è sopra l'elemento Finché il cursore rimane sull'elemento
:active Nel momento esatto in cui l'elemento viene cliccato Solo mentre il tasto del mouse è premuto

Testa l'esercizio nel browser: passa il cursore sul pulsante (diventa blu) e poi fai clic tenendo premuto il mouse (diventa rosso). Appena rilasci il tasto torna allo stato hover (blu) o normale.

Passo 4 — Personalizzazione avanzata (opzionale)

Aggiungi uno stile base al pulsante per un aspetto più curato:

style.css — Stilizzazione avanzata
          button {
            padding: 10px 24px;
            font-size: 1rem;
            border: none;
            border-radius: 6px;
            background-color: lightgray;
            cursor: pointer;
            transition: background-color 0.2s;
          }

          button:hover {
            background-color: blue;
            color: white;
          }

          button:active {
            background-color: red;
            color: white;
          }

Proprietà aggiuntive:

  • border: none; — rimuove il bordo predefinito del pulsante
  • border-radius: 6px; — angoli arrotondati
  • cursor: pointer; — mostra la manina al passaggio del mouse
  • transition: background-color 0.2s; — anima il cambio di colore

Risultato atteso

Il pulsante si comporterà così:

  • Stato normale: grigio chiaro (o stile predefinito del browser)
  • Al passaggio del mouse (:hover): sfondo blu
  • Durante il clic (:active): sfondo rosso

Approfondimenti

:active funziona su qualsiasi elemento cliccabile:

  • a:active — link durante il clic
  • li:active — elemento di lista durante il clic
  • div:active — contenitore generico durante il clic

La pseudo-classe :active è utile per fornire un feedback visivo immediato all'utente, confermando che l'elemento ha ricevuto il clic.
