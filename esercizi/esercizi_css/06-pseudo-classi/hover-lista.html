Pseudo-classe :hover su Lista

⏱ 15 minuti · ul · li · :hover · pseudo-classi

Descrizione

In questo esercizio imparerai a usare la pseudo-classe CSS :hover per modificare l'aspetto degli elementi di una lista non ordinata (<ul>) quando il cursore del mouse vi passa sopra. Le pseudo-classi permettono di applicare stili in risposta alle azioni dell'utente, senza scrivere JavaScript.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con una lista non ordinata contenente almeno quattro elementi:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-classi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <ul>
                <li>Elemento 1</li>
                <li>Elemento 2</li>
                <li>Elemento 3</li>
                <li>Elemento 4</li>
              </ul>
            </body>
          </html>

Passo 2 — Creare il file CSS con la pseudo-classe :hover

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. All'interno del file CSS, definisci la regola per la pseudo-classe :hover sugli elementi <li>:

style.css
          li:hover {
            color: red;
          }

La sintassi li:hover si legge: "applica questo stile agli elementi <li> solo quando il cursore del mouse vi si trova sopra".

Passo 3 — Comprendere la pseudo-classe :hover

Componente Valore Significato
li selettore Seleziona tutti gli elementi <li> della pagina
:hover pseudo-classe Si attiva quando il cursore del mouse passa sopra l'elemento
color proprietà CSS Cambia il colore del testo
red valore Il testo diventa rosso al passaggio del cursore

Passo 4 — Personalizzazione avanzata (opzionale)

Puoi arricchire l'effetto hover con altre proprietà CSS per un risultato più visivo:

style.css — Stilizzazione avanzata
          li {
            padding: 6px 10px;
            cursor: pointer;
            transition: color 0.2s;
          }

          li:hover {
            color: red;
            font-weight: bold;
          }

Proprietà aggiuntive:

  • cursor: pointer; — mostra la manina al passaggio del mouse
  • transition: color 0.2s; — anima il cambio di colore in 0.2 secondi
  • font-weight: bold; — rende il testo in grassetto al hover

Risultato atteso

Aprendo index.html nel browser, gli elementi della lista appariranno normali. Passando il cursore del mouse su un elemento, il suo testo diventerà rosso. Spostando il cursore altrove, il testo tornerà al colore originale.

Approfondimenti

La pseudo-classe :hover può essere applicata a qualsiasi elemento HTML:

  • a:hover — link al passaggio del mouse
  • button:hover — pulsante al passaggio del mouse
  • div:hover — qualsiasi contenitore al passaggio del mouse
  • tr:hover — riga di tabella al passaggio del mouse
