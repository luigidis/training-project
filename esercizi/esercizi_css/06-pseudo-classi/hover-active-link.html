Pseudo-classi :hover e :active su Link

⏱ 15 minuti · a · :hover · :active · pseudo-classi

Descrizione

In questo esercizio applicherai le pseudo-classi :hover e :active a un link (<a>) per modificarne il colore del testo in due momenti diversi: quando il cursore vi passa sopra, e quando viene cliccato. I link hanno anche altre pseudo-classi specifiche che scoprirai negli approfondimenti.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML chiamato index.html con un link:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio Pseudo-classi</title>
              <link rel="stylesheet" href="style.css" />
            </head>
            <body>
              <a href="#">Link di esempio</a>
            </body>
          </html>

Passo 2 — Creare il file CSS con :hover e :active

Crea un nuovo file chiamato style.css nella stessa cartella del file HTML. Il link deve diventare rosso al passaggio del mouse e blu quando viene cliccato:

style.css
          a:hover {
            color: red;
          }

          a:active {
            color: blue;
          }

Passo 3 — Le pseudo-classi specifiche dei link

I link <a> hanno quattro pseudo-classi dedicate. È importante rispettarne l'ordine nella scrittura del CSS per evitare conflitti:

Pseudo-classe Quando si attiva Ordine consigliato
:link Link non ancora visitato 1°
:visited Link già visitato in precedenza 2°
:hover Cursore del mouse sopra il link 3°
:active Link in fase di clic 4°

Il trucco per ricordare l'ordine corretto è la sigla LoVe HAte (Link, Visited, Hover, Active).

Passo 4 — Personalizzazione avanzata (opzionale)

Applica stili più completi al link utilizzando tutte e quattro le pseudo-classi:

style.css — Stilizzazione avanzata
          a {
            font-size: 1.1rem;
            text-decoration: none;
            font-weight: bold;
          }

          a:link {
            color: navy;
          }

          a:visited {
            color: purple;
          }

          a:hover {
            color: red;
            text-decoration: underline;
          }

          a:active {
            color: blue;
          }

Proprietà aggiuntive:

  • text-decoration: none; — rimuove la sottolineatura predefinita del link
  • text-decoration: underline; — aggiunge la sottolineatura solo al hover
  • a:visited — stile per i link già cliccati in precedenza

Risultato atteso

Il link si comporterà così:

  • Stato normale: colore predefinito del browser (blu)
  • Al passaggio del mouse (:hover): testo rosso
  • Durante il clic (:active): testo blu

Approfondimenti

Perché usare href="#" nell'esercizio?

Il valore # crea un link che punta alla stessa pagina, evitando di navigare altrove. È utile per testare gli stili senza uscire dalla pagina. Nei progetti reali si sostituisce con l'URL effettivo della destinazione.
