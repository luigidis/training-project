Base Esercizio CSS #4

Stilizzare un Link con CSS

⏱ 25 minuti · display · text-decoration · text-align · line-height

Descrizione

In questo esercizio imparerai a trasformare un semplice link in un elemento visivamente più interessante, simile a un pulsante, utilizzando varie proprietà CSS come display, width, height, text-decoration, text-align, e line-height.

Passo 1 — Creare la struttura HTML

Crea un nuovo file HTML con un semplice link:

index.html
          <!DOCTYPE html>
          <html>
            <head>
              <title>Esercizio 10</title>
              <style>
                /* Il CSS andrà qui */
              </style>
            </head>
            <body>
              <a href="#">Clicca qui</a>
            </body>
          </html>

Passo 2 — Trasformare il link in blocco

Per default, i link (<a>) sono elementi inline, il che significa che non accettano proprietà come width e height. Per poterle applicare, dobbiamo trasformarlo in un elemento inline-block:

CSS — Display inline-block
          a {
            display: inline-block;
          }

Differenza tra inline e inline-block:

  • inline — Non accetta width/height, si adatta al contenuto
  • inline-block — Accetta width/height ma resta in riga con altri elementi
  • block — Occupa tutta la larghezza disponibile, va a capo

Passo 3 — Applicare dimensioni e vincoli

Ora che il link è inline-block, possiamo applicare le dimensioni:

CSS — Dimensioni
          a {
            display: inline-block;
            width: 300px;
            height: 60px;
            min-height: 50px;
            max-width: 350px;
          }

Passo 4 — Stilizzazione del testo e layout

Aggiungiamo proprietà per migliorare l'aspetto del link:

CSS — Stile completo
          a {
            display: inline-block;
            width: 300px;
            height: 60px;
            min-height: 50px;
            max-width: 350px;
            background-color: yellow;
            color: blue;
            text-decoration: none;
            text-align: center;
            line-height: 60px;
          }

Passo 5 — Comprendere ogni proprietà

Proprietà Valore Significato
display inline-block Permette di applicare width/height mantenendo il comportamento inline
width 300px Il link è largo 300 pixel
height 60px Il link è alto 60 pixel
min-height 50px L'altezza minima garantita è 50px
max-width 350px La larghezza massima consentita è 350px
background-color yellow Sfondo giallo per il link
color blue Testo di colore blu
text-decoration none Rimuove la sottolineatura predefinita dei link
text-align center Centra il testo orizzontalmente
line-height 60px Altezza della riga uguale all'altezza del link per centrare verticalmente il testo

Passo 6 — Aggiungere effetti hover (opzionale)

Per rendere il link più interattivo, puoi aggiungere uno stile che cambia quando il mouse ci passa sopra:

CSS — Con effetto hover
          a {
            display: inline-block;
            width: 300px;
            height: 60px;
            min-height: 50px;
            max-width: 350px;
            background-color: yellow;
            color: blue;
            text-decoration: none;
            text-align: center;
            line-height: 60px;
            transition: background-color 0.3s;
          }

          a:hover {
            background-color: orange;
          }

La pseudo-classe :hover si applica quando il mouse passa sopra l'elemento. La proprietà transition crea un'animazione fluida del cambio di colore.

Risultato atteso

Il link avrà l'aspetto di un pulsante con:

  • Larghezza di 300px (massimo 350px)
  • Altezza di 60px (minimo 50px)
  • Sfondo giallo e testo blu
  • Nessuna sottolineatura
  • Testo centrato sia orizzontalmente che verticalmente
  • Effetto hover che cambia lo sfondo in arancione (opzionale)

Approfondimenti

Il trucco di line-height per centrare verticalmente:

Quando line-height è uguale all'height del contenitore e il testo è su una sola riga, il testo viene automaticamente centrato verticalmente. Questo è un trucco CSS molto utilizzato per elementi come pulsanti e badge.

Altre pseudo-classi utili per i link:

  • a:link — Link non visitati
  • a:visited — Link già visitati
  • a:hover — Link quando il mouse ci passa sopra
  • a:active — Link nel momento del click
