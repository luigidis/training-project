Intermedio Progetto #2

Ricrea la CSS ToDoList

⏱ 90 minuti · HTML · CSS · Liste · Pseudo-classi · Pseudo-elementi

Obiettivo

Osserva attentamente la pagina web mostrata nel documento PDF qui sotto e ricreala il più fedelmente possibile usando solo HTML e CSS. Hai a disposizione il logo del progetto scaricabile tramite il pulsante apposito.

Anteprima della pagina da ricreare

Studia la pagina nel dettaglio: osserva la struttura, i colori, i font, come sono stilizzati gli elementi della lista e le interazioni al passaggio del mouse.

↓ Scarica il PDF ↓ Scarica il Logo (PNG)

Come svolgere l'esercizio

Crea una cartella sul tuo computer chiamata toboolist e al suo interno organizza i file così:

Struttura consigliata
toboolist/
├── index.html
├── style.css
└── img/
    └── logo_css.png

Suggerimenti

  • 👁 Analizza prima l'intera pagina nel PDF prima di scrivere una sola riga di codice. Identifica le macro-sezioni: intestazione, lista attività, area di input.
  • 📋 La lista di task è un elemento <ul> con elementi <li>. Pensa a come usare pseudo-classi come :hover per evidenziare le righe al passaggio del cursore.
  • 🎨 Prova a estrarre i colori principali osservando sfondi, testi e bordi. Puoi usare valori approssimativi, non deve essere perfetto al pixel.
  • 🖼 Usa il tag <img> per inserire il logo. Controlla il percorso relativo dalla cartella img/.
  • 📱 Non preoccuparti della versione mobile per ora: concentrati sul layout desktop.
  • ✅ Costruisci sezione per sezione e controlla il risultato nel browser ad ogni passaggio, senza aspettare di aver finito tutto.

Checklist finale

  • ☐ Struttura HTML semantica
  • ☐ CSS in file esterno collegato
  • ☐ Logo visibile nella pagina
  • ☐ Lista task stilizzata
  • ☐ Effetti :hover sugli elementi
  • ☐ Colori e font simili all'originale
  • ☐ Pagina leggibile nel browser
