Intermedio Progetto #1

Ricrea il Sito MensSano

⏱ 90 minuti · HTML · CSS · Layout · Immagini

Obiettivo

Osserva attentamente la pagina web mostrata nel documento PDF qui sotto e ricreala il più fedelmente possibile usando solo HTML e CSS. Hai a disposizione tutti gli assets grafici (immagini e logo) scaricabili tramite il pulsante apposito.

Anteprima della pagina da ricreare

Studia la pagina nel dettaglio: osserva la struttura, i colori, i font, le sezioni e come sono posizionati gli elementi.

↓ Scarica il PDF ↓ Scarica gli Assets (immagini)

Come svolgere l'esercizio

Crea una cartella sul tuo computer chiamata menssano e al suo interno organizza i file così:

Struttura consigliata
menssano/
├── index.html
├── style.css
└── img/
    ├── logo.svg
    ├── monitor.jpg
    ├── graph.jpg
    ├── pattern.png
    ├── tim-1.jpg
    └── tim-2.jpg

Suggerimenti

  • 👁 Analizza prima l'intera pagina nel PDF prima di scrivere una sola riga di codice. Identifica le macro-sezioni: header, hero, contenuto, footer.
  • 🎨 Prova a estrarre i colori principali osservando sfondi, testi e bottoni. Puoi usare valori approssimativi, non deve essere perfetto al pixel.
  • 🖼 Usa i tag <img> per le fotografie e <img> anche per il logo SVG. Controlla il percorso relativo dalla cartella img/.
  • 📱 Non preoccuparti della versione mobile per ora: concentrati sul layout desktop.
  • ✅ Costruisci sezione per sezione e controlla il risultato nel browser ad ogni passaggio, senza aspettare di aver finito tutto.

Assets inclusi

File Tipo Utilizzo nella pagina
logo.svg Logo vettoriale Header / navbar
monitor.jpg Fotografia Sezione hero o prodotto
graph.jpg Fotografia Sezione dati / statistiche
pattern.png Texture Sfondo decorativo
tim-1.jpg Fotografia Sezione team / persone
tim-2.jpg Fotografia Sezione team / persone

Checklist finale

  • ☐ Struttura HTML semantica
  • ☐ CSS in file esterno collegato
  • ☐ Tutte le immagini visibili
  • ☐ Colori e font simili all'originale
  • ☐ Layout con sezioni distinte
  • ☐ Pagina leggibile nel browser

Concetti usati

  • Struttura HTML
  • Selettori CSS
  • Box Model
  • Flexbox / Grid
  • Immagini e SVG
  • Colori e tipografia
