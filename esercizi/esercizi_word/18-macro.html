Avanzato Esercizio #18

Creare e Usare una Macro

⏱ 30 minuti · Macro Word · Registratore macro · Sostituisci testo · Automazione
Nota — Solo Word Desktop

Le macro non sono disponibili su Word Online. Questo esercizio richiede Word installato sul PC con la scheda Sviluppo abilitata.

Descrizione

In questo esercizio imparerai a registrare una macro in Word — una sequenza di azioni automatizzate che puoi ripetere con un solo clic o tasto di scelta rapida.

Fase 1 — Abilitare la scheda Sviluppo

Se la scheda Sviluppo non è visibile nel ribbon, abilitala:

  1. Vai su File → Opzioni → Personalizza barra multifunzione
  2. Nella colonna di destra, spunta la voce Sviluppo
  3. Clicca OK

Fase 2 — Apertura del documento

Riprendi il documento su cui stai lavorando (puoi usare uno qualsiasi dei file creati negli esercizi precedenti, preferibilmente il documento completo). Assicurati che contenga del testo con almeno 5 parole specifiche che vuoi modificare.

Fase 3 — Registrazione della macro

  1. Vai su Sviluppo → Registra macro (oppure Visualizza → Macro → Registra macro).
  2. Dai un nome alla macro (es. ModificaParole) — senza spazi.
  3. Opzionalmente, assegna un tasto di scelta rapida (es. CTRL+MAIUSC+M) o un pulsante nella barra degli strumenti.
  4. Clicca OK per iniziare la registrazione.
  5. Esegui le azioni che vuoi registrare — ad esempio, usa Home → Modifica → Sostituisci (CTRL+H) per sostituire una parola con un'altra.
  6. Chiudi la finestra Sostituisci.
  7. Clicca su Sviluppo → Interrompi registrazione (o il pulsante quadrato nella barra di stato in basso).

Fase 4 — Utilizzo della macro

Usa la macro per modificare almeno 5 parole nel documento:

  1. Puoi eseguire la macro da Sviluppo → Macro → Esegui oppure con il tasto di scelta rapida assegnato.
  2. Verifica che le sostituzioni siano avvenute correttamente nel documento.

Fase 5 — Salvataggio con macro

Per conservare le macro, il file deve essere salvato nel formato Word con attivazione macro:

File → Salva con nome → Documento Word con attivazione macro (*.docm)

Verifica finale

  • La scheda Sviluppo è visibile nel ribbon
  • La macro è stata registrata con un nome descrittivo
  • La macro ha modificato almeno 5 parole nel documento
  • Il file è salvato in formato .docm

Indice delle fasi

  1. Abilitare scheda Sviluppo
  2. Apertura documento
  3. Registrazione macro
  4. Utilizzo macro
  5. Salvataggio .docm

Strumenti usati

  • Sviluppo → Registra macro
  • CTRL+H (Sostituisci)
  • Interrompi registrazione
  • Formato .docm
